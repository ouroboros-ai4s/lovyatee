## Antibody-Antigen Affinity Datasets SRC

> 20 个 datasets 中的每条 data 可抽象建模为 `((ab, ag), label, assay, condition, replicate, source)`:
>
> - `(ab, ag)`: 每条数据本身为 ab-ag pair.
> - `label`: affinity label, $K_D$ 值、bind / no-bind binding、score 等多种形式.
> - `assay`: 测量方法，例如 SPR、BLI、ELISA.
> - `condition`: 测量条件，例如温度、pH、浓度或实验构建体.
> - `replicate`: 同一 pair 的第几次重复实验.
> - `source`: 记录来自哪个 SRC.
>
> **Motivation**: 针对 20 个抗体–抗原亲和力数据源，考虑到各数据集在内部 schema、抗体构建体、实验标签及记录粒度等方面存在显著异构性，首先将每条数据统一抽象为 ((ab, ag), label, assay, condition, replicate, source)，分别表示抗体–抗原配对、监督标签、测量方法、实验条件、重复测量及来源信息。在此基础上，进一步对各组成维度进行分层解析与统计，包括抗体序列类型、链长分布、序列唯一性及结构关联等，以建立跨数据源的统一统计视角，明确不同数据源的组成特征、数据粒度与可用监督信息，为后续数据清洗、跨源去重、数据整合及训练集构建提供依据。

## Antibody

> 有 Heavy 和 Light 的 "Unique" 字段都是 `(heavy, light)` 二元组精确去重. "Unique with PDB_ID" 是按 Unique 后的 sequence 计数.
> Total Unique 计数方式为统一转 string, 如果有 Heavy 和 Light 用 "/" 拼接成 string.

以下为 Antibody 相关 Table 中重要字段的说明.

> 第一张是 Sequence Type，关注数据的类型构成，包括 Heavy + Light、Heavy-only、Light-only、scFv 和 Nanobody 等，主要用于评估不同链型与抗体构建体的数据规模，为后续的数据筛选、链提取和训练集构建提供依据。
>
> 第二张是 Heavy / Light Length Distribution，关注实际提取到的两条链的长度组合，主要用于检查序列完整性、缺链情况和异常长度分布，并为下游模型的输入长度设置、截断策略以及结构预测模型的数据预处理提供参考。
>
> 两者的区别在于：第一张统计序列类型，第二张统计实际序列形态。后续还可以增加结构与监督信号可用性的统计，评估具有可用实验结构、复合物信息和区域注释的数据覆盖率，从而进一步判断这些资源对序列预训练、结构预测和抗体–抗原界面任务的支持程度。

| Key | 含义 | 说明 |
| --- | --- | --- |
| Sequence Type | 抗体序列类型 | 根据原始数据字段、链槽位及已有构建体标签划分的类别。 |
| Records | 原始记录数 | 原始数据中的记录数量，同一序列可能重复出现。 |
| Unique | 唯一序列数 | 按对应数据集定义的去重规则统计。 |
| Unique with PDB_ID | 关联 PDB 的唯一序列数 | 去重后具有关联 PDB_ID 的序列数量，不等同于具有可用实验结构监督的序列数量。 |
| Description | 类型说明 | 描述分类依据、序列槽位特征及分类限制。 |

| Sequence Type | 含义 |
| --- | --- |
| IgG | 完整免疫球蛋白 G（Immunoglobulin G）构建体，通常包含 Heavy、Light 两条完整链及恒定区；仅在原始数据显式标注为 IgG 时归入该类别，不能仅凭 Heavy + Light 槽位直接判定。 |
| Heavy + Light | 同时存在 Heavy 和 Light 两个序列槽位。若原始数据没有明确标注构建体类型，则不能直接判定为 IgG、Fab 或 Fv。 |
| Heavy-only | 仅存在 Heavy 序列槽位，可能是 VH-only 或缺失 Light 链的其他构建体，不能仅凭槽位确定具体类型。 |
| Light-only | 仅存在 Light 序列槽位，可能是 VL-only 或缺失 Heavy 链的其他构建体。 |
| Nanobody / VHH | 原始数据显式标记为 Nanobody 或 VHH 的记录，按单域抗体类别处理。 |
| Fab | 根据源表标签及序列槽位归类的 Fab 构建体，通常包含 Heavy、Light 两侧的抗体片段。 |
| Fv | Heavy 和 Light 均为较短的可变区序列，且原始数据或分类规则将其归为 Fv。 |
| scFv | 原始数据显式标记或归类为 scFv 的记录。可能以完整单链形式存储，也可能占据不同的原始序列槽位。 |
| VH + VL-CL | Heavy 为较短的可变区序列，Light 包含较长的 VL–CL 构建体。 |
| VH-CH1 + VL | Heavy 包含较长的 VH–CH1 构建体，Light 为较短的 VL 序列。 |
| CDR-H 1~3 | 只保存 CDR-H1、CDR-H2、CDR-H3 三个重链超变区的序列，不含框架区、可变区全长或完整链槽位。 |
| CDR-H3 | 只保存 CDR-H3 单个重链超变区的序列，其余重链与轻链序列均不在原始表中。 |
| Unknown | 原始构建体标签缺失，或记录无法根据现有字段归入已定义的类别。 |

## Antigen

以下为 Antigen 相关 Table 中重要字段的说明.

> Antigen 统计以 source-native antigen entity 为核心单位. 优先使用原始 antigen ID/name、construct 和 antigen chain 定义实体；存在可靠序列时再统计唯一抗原序列. 这样可以区分实验记录重复、不同构建体和真正不同的抗原.
>
> Antigen 的结构、序列和数据库注释统一压缩到同一张表中. `PDB / UniProt` 采用唯一抗原实体粒度统计 2 × 2 覆盖结果. 共享参考 PDB 不等同于每条记录都有独立实验结构.
>
> Antigen 的长度直接放在同一张表中, 用于检查序列完整性和构建体差异. 无法取得序列时报告为 unavailable, 不从物种名或抗原名称推断序列.

| Key | 含义 | 说明 |
| --- | --- | --- |
| Records | 原始记录数 | 原始 affinity 或 structure-affinity 表中的记录数量. 同一抗原可能因不同抗体、重复测量、突变体或 PDB 记录重复出现. |
| Unique ag entity | 唯一抗原实体数 | 按 source-native antigen ID/name、construct 和 antigen chain 等字段定义并去重的抗原实体数量. |
| Unique ag sequence | 唯一抗原序列数 | 对直接提供或可靠重建的抗原序列标准化后去重的数量. |
| PDB / UniProt coverage | 结构和数据库覆盖 | 在唯一抗原实体粒度统计 `PDB=0/UniProt=0`, `PDB=0/UniProt=1`, `PDB=1/UniProt=0`, `PDB=1/UniProt=1`. PDB 必须是 antigen-side 结构证据. |
| Antigen Length | 抗原序列长度 | 报告可用抗原序列的长度范围、unique lengths 或中位数. 直接序列与 PDB 重建序列应分别注明. |
| Antigen Evidence | 抗原证据来源 | 使用 `Direct sequence`, `PDB-derived sequence`, `Reference PDB` 或 `Unavailable` 表示序列和结构证据的来源. |
| Antigen Provenance | 抗原来源关系 | 记录 `Fixed target`, `Source-native`, `Shared upstream source` 等来源关系, 用于避免跨 SRC 重复累计. |
| Description | 抗原说明 | 描述抗原身份、构建体、链、序列来源、PDB/UniProt 限制和统计口径. |

| Antigen Evidence / Provenance | 含义 |
| --- | --- |
| Fixed target | 多条记录使用同一个固定抗原或抗原构建体, 统计时按一个抗原实体计数. |
| Direct sequence | 原始数据表直接提供与记录对应的抗原序列. |
| PDB-derived sequence | 原始表没有完整抗原序列, 但可以从 PDB entry/entity/chain 重建序列; 该序列属于派生数据. |
| Reference PDB | PDB 仅作为共享参考结构或 parent complex, 不证明每条记录都有独立实验复合物结构. |
| Unavailable | 当前 source 没有足够字段提供抗原序列、PDB 或 UniProt 证据. |
| Shared upstream source | 多个 SRC 来自同一批上游数据; 跨源汇总时应按测量身份或上游记录去重. |

## Affinity

> 行粒度 `(label, assay, condition)` 三元组. 只写实际观测到的组合, 不铺笛卡尔积. 三元组在某 SRC 内只出现一次.

| Key | 含义 | 说明 |
| --- | --- | --- |
| Label | 监督信号类型 | 全局封闭词表, 见下表. 同一 SRC 可出现多个. |
| Assay | 测量方法 | 全局封闭词表, 见下表. 源内未标注记 `unknown`, 不据数值形态反推. |
| Condition | 测量条件 | R 内封闭词表. 只写源内真实存在的字段, 每个 SRC 的取值在表前单独列出. |
| Replicate | 重复结构 | 聚合描述, 不是行键. 固定文法, 见下. |
| Record pairs | 原始 (ab, ag) 配对记录数 | 该三元组下 label 有值的记录行数. 重复测量、重复收录分别计数. |
| Unique pairs | 唯一 (ab, ag) 配对 | 去重键每 SRC 不同, 写在对应 H3 下方的 `>` 引用块里. |
| Description | 说明 | 该组合的构成、量纲、边界值与注意事项. |

| Label | 含义 |
| --- | --- |
| `Kd_M` | 保留原值的解离常数, 单位为 M. |
| `log_Kd` | 已取对数或负对数的 Kd, 量纲随源. |
| `ddG` | 突变导致的结合自由能差, 需配 WT / mutant 状态. |
| `IC50` | 半数抑制浓度. |
| `EC50` | 半数有效浓度, 多为细胞或展示层面读出. |
| `enrichment` | 富集、排序或分选信号, 不是绝对亲和力. |
| `ordinal` | 有序类别 (如 low / mid / high), 类别内无顺序. |
| `binary` | 结合 / 不结合判定. |
| `predicted` | 模型预测或计算值, 不是实验测量. 必须与实验 label 分开. |
| `not_recorded` | 源内有该 (ab, ag) 配对但无可用 label. |

| Assay | 含义 |
| --- | --- |
| `SPR` / `BLI` | 表面等离子共振 / 生物膜层干涉, 动力学拟合. |
| `ITC` / `KinExA` | 等温滴定量热 / 动力学排除分析, 溶液相. |
| `ELISA` | 固相酶联读出, 多为相对比值. |
| `flow` | 流式细胞术, 常为分选门限或相对荧光. |
| `yeast_display` / `phage_display` | 展示筛选, 读数为富集而非 Kd. |
| `NGS_seq` | AlphaSeq / MAGMA-seq / Tite-Seq 等测序读出. |
| `computational` | FoldX / Rosetta / Flex ddG 等计算值. |
| `unknown` | 源内未提供方法字段. |
