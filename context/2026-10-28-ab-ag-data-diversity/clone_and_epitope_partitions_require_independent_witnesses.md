# Clone And Epitope Partitions Require Independent Witnesses

## time

## description

证明克隆划分与表位划分互不细化，需要两个方向各自独立的见证：

- **C ⋠ E**（克隆不细化表位）：需要**同一克隆、不同表位**。
- **E ⋠ C**（表位不细化克隆）：需要**同一表位、不同克隆**。

文献里常被引作这两条的，其实各自只支持一个方向，且强度不如被引用时暗示的：

**PG9/PG16（第 22 条）** —— 体细胞相关的两个抗体结合同一类表位但识别细节不同。这支持的是「同一表位、不同精细模式」。「精细模式不同」不等于「表位不同」：两个精细模式完全可能都属于同一个表位。所以它最多支持 E ⋠ C 的一个弱形式，不能支持 C ⋠ E。

**Sangesland（第 25 条）** —— germline 编码的氨基酸结合基序驱动免疫显性公共应答。这支持的是「公共性有 germline 来源」，不是「不同谱系采用同一精细结合模式」。后者需要结合层面的证据，摘要不足以确认。所以它也不构成 E ⋠ C 的完整见证。

命题落在这里：**现有引用把单向证据当双向用。** 这不是说结论错 —— 而是说这两个方向目前都缺合格的见证，需要新的实验（同一克隆内成员的表位分箱；跨供体同一表位的配对谱系追踪）。

具体实例（用被引条目本身）：PG9 与 PG16 是体细胞相关的两个抗体，若把「识别细节不同」读成「表位不同」，就同时默认了 C ⋠ E 与 E ⋠ C 两个方向；但它们共享同一类表位这一点恰恰说明二者可能属于同一表位，那么它支持的是「同一表位、不同精细模式」，即 E ⋠ C 的一个弱形式，与 C ⋠ E 无关。这个读法差别不依赖新数据，只需把「精细模式」与「表位」分开。

可证伪内容：若找到同一克隆内被实验分箱到不同表位的成员对，C ⋠ E 成立；若找到跨谱系被分箱到同一表位的抗体对，E ⋠ C 成立。两者都成立时，「克隆结构不能作为表位覆盖的代理」这句话才有完整的经验基础。

边界：即使两个方向都有见证，也不推出两个划分统计独立，更不推出代理误差无界 —— 一百万对里只有两对违反时，整体代理误差仍然很小。存在性命题不支持定量结论。
