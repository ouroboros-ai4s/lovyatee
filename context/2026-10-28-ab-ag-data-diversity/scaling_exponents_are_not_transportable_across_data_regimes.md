# Scaling Exponents Are Not Transportable Across Data Regimes

## time

2026-10-21

## lineage

- ../bodn/2026-10-21-abag-diversity-data-volume-performance-survey-s5.md: 第 3 条（Hestness 2017，多个监督任务上误差随训练集规模近似幂律，仅在实测区间内可外推）、第 4 条（Kaplan 2020）、第 5 条（Hoffmann 2022）；反例取第 1、2 条。

## relation

None.

## description

用学习曲线外推「还要收多少数据」时，可搬的只有程序，不能搬指数。

本条与 [[bio_foundation_model_data_scaling_has_no_established_law]] 分工：那条问「生物基础模型上有没有稳定的指数可拟合」（答案是在被观测区间内没看到），本条问「拟合出来的指数能不能搬到别的任务或区间」（答案是不能，缺独立确认）。两条互不细化。

Hestness 2017 的程序是：在多个数据规模上实测误差，只在实测区间内拟合幂律并外推。它的证据是跨多个领域的经验学习曲线上、误差随训练集规模近似幂律的区间（s5 第 3 条只记到这个程度，未列具体任务数）—— 前提同分布、任务固定、测试集与训练集同源。这个前提在收集规划里恰好不成立：新收抗原改变的是分布本身，不只是样本量。**Hestness 不提供「如何选缩放变量」的方法**，它只是说选定变量之后误差在那个区间内像幂律。

Kaplan 2020 与 Hoffmann 2022 的指数针对语言模型、针对交叉熵或下游 loss，不能搬。注意 Hoffmann 的原结论是「算力最优时参数量与数据量同倍增长，现有模型普遍欠训练」，它变的是 token 数，不是分布；把它读成「大模型能补偿狭窄覆盖」是反向使用。

必要与充分要分开。**必要**：要在 ab-ag 上外推，实测区间必须覆盖目标区间，且 x 轴必须是目标量本身 —— 这是本条论证的直接推论。**不充分**：满足这两条之后，指数仍可能因分布改变而变（新收抗原改变分布），所以「区间对上了就能搬」不成立。

x 轴的选择是独立的一步，且不可互推。配对数、抗原数、覆盖度增量是三个不同的 x 轴：配对数可以涨而覆盖度增量恒为零（见 [[annual_antigen_targets_require_marginal_interface_coverage_estimates]]）。在配对数上拟合的曲线不能换算成覆盖度上的曲线。

量级说明（我构造的数值，非原文数据）：若高数据区间的真实指数是 0.05，而按低区间的 0.3 规划，要达到同一 4 倍 loss 降幅分别需要 4^(1/0.05) ≈ 1.1×10¹² 倍与 4^(1/0.3) ≈ 102 倍数据 —— 相差十个数量级。所以「从一万对推到一百万对」不是算力问题，是拟合区间问题。

可证伪内容：若在某一 ab-ag 任务与规模区间拟合的指数，能在留出的另一任务或另一规模区间上把性能预测到相对误差 ±10% 以内，则「不可移植」在该族内失效。
