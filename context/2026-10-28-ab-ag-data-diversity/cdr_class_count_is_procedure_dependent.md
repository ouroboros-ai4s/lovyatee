# CDR Class Count Is Procedure Dependent

## description

对同一组 CDR 结构，不同聚类程序产生的非空类别数可以不同。

三个可比的数字：Chothia 1987 覆盖 20 种 CDR 长度组合，North 2011 用方向统计距离 + 亲和传播聚类覆盖 28 种，Nowak 2016 的长度无关规范类在三个 NGS repertoire 上比标准方法多归类约 13.5 万条序列（约 20%）。

**这三个数不能拼成一条「类别数随方法改进而单调增加」的曲线** —— 数据与程序同时变化，没有受控比较。所以命题只写到存在性：程序是计数的一个自变量。

必须区分两个容易混淆的统计量：

- **新增归类的序列比例**（Nowak 的 +20%）：有多少原本落在所有类之外的序列被纳入。
- **新增类别的比例**：类的数量增加了多少。

两者不同，且方向可以相反。覆盖率上升时，类别数完全可以下降 —— 例如程序乙把此前未归类的结构收入已有的边界簇。所以「更多序列被分类」不蕴涵「更多类」。

对数据收集的直接含义：「CDR 结构有 N 个类」不是物理量，N 不能作为目标写入数据收集指标。可写的量是「在固定分类程序版本与参数下，被占据的类集合」。

## spill

S1=75 判「标题讲非空类别数，举证却是 CDR 长度组合覆盖率（20 对 28）与序列归类率（+20%）」。这三个数字来自不同结构集，不构成「同一组 CDR 结构上换程序」这一断言域的实例。S3=0、S6=0，F4=25 无可证伪段。

**复活条件**：找到在**同一组结构**上跑两个分类程序并报非空类别数的对照；或把标题从「类别数」改为「分类程序是计数的自变量」以匹配现有证据。
