# Footprint Overlap Does Not Predict Escape Spectrum

2026-10-21

## description

Greaney 2021 用酵母展示深度突变扫描制图 RBD 全部替换对单个抗体识别的影响，每个抗体得到一条跨位点与替换的逃逸谱。原文报告：**结构足迹相似的两个抗体可以有不同逃逸谱**。

方向与直觉相反。「结构相似 ⇒ 功能相似」在这里失败。

原文只给反例类，未给效应量。以下是我的推论，标为待检验假设：若接触残基与逃逸谱测量的是同一个「表位同一性」，那么按足迹匹配的抗体对在逃逸距离上也应匹配；实测不匹配的这对说明两个量不同。可执行的检验是取足迹 Jaccard ≥ 0.8 的抗体对，计算足迹距离与逃逸谱距离的秩相关。

后果分两处。对 (b)：若以足迹重叠作去重判据，会把功能上不同的特异性合并，误合并率必须实测而非假定 —— 结构数据能不能替代功能测量，是一个可测的经验问题，不是默认成立的。对 (a)：以足迹计的「每抗原表位数」会高于功能覆盖，两者之差随抗原而异。

本条挣得的压缩：把 Greaney 的反例类折成一个该文未陈述的推论 —— 「结构数据能否替代功能测量」不是方法学偏好问题，而是一个可测的经验问题，其答案由误合并率决定。这是本条新增的内容。

只证了一个方向。逃逸谱相似是否蕴含足迹相似，原文未测 —— 存在「逃逸谱相同而足迹不同」的情形完全可能（例如逃逸只由少数关键位点决定）。所以在两个量之间既不能正推也不能反推。

本条是 [[epitope_partitions_are_not_axiomatically_nested]] 的成对度量级实例：那条说五类测量对象之间无必然映射，并自陈证据缺口在 RBD panel 之外；本条补上 RBD panel 上的一个具体反例类。

可证伪内容：在独立留出 panel 上，足迹高重叠对的足迹距离与逃逸谱距离的秩相关若显著接近 1（例如下界高于 0.8），则足迹对该任务足够，本条被推翻。
