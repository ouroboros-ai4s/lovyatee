# CDR Class Map Is Not A Function In Either Direction

## time

## description

序列与构象类之间的对应在两个方向上都不是函数：

**方向一，同一序列归于多类。** Fernández-Quintero 2020 在 µs–ms 尺度上观察到 CDR 环在规范簇之间跃迁，2019 进一步量化了 CDR-L3 的跃迁速率。单一晶体结构的类归属是这个序列在一个观测窗口内的取值，不是它的固有属性。方向二，**序列不相近可归同一类**：North 2011 明确报告了两条序列不相近的 CDR 落在同一构象簇。

两条都只作**存在性命题**，且各有其证据边界：

- 方向一由 MD 轨迹支持，但 MD 跃迁本身不证明「溶液与晶体给出不同归属」—— 那需要同一分子的成对实验结构，目前未核。
- 方向二只证明「序列距离大」不蕴涵「结构距离大」，不证明「大多数情况如此」。

合起来的后果：**序列多样性 ≠ 结构多样性，且差异不是单向的尺度差，是映射本身多对多。** 这与 [[sequence_diversity_bias_has_no_fixed_sign]] 相容但不等价：那条讲同一个量在两个表示下的偏差符号不固定，这条讲两个表示之间的关系不是函数。

可操作要求：报 CDR 结构多样性时用被占据的类集合，不用「序列 → 类」的指派计数。指派计数会同时低估（同类多序列应以一类计）与高估（同一序列跨阶段跃迁应以分布计）。

边界：若下游任务只需要一个确定指派（例如给每条序列打一个标签供检索），可以用最大占据概率指派，但必须说明这是有损的确定化，损失量未定义。
