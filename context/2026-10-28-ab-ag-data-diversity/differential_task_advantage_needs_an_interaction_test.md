# Differential Task Advantage Needs An Interaction Test

## time

2026-10-20

## description

「方法 A 在任务 1 上显著、在任务 2 上不显著」不等于「A 相对 B 的优势在两个任务之间有差异」。后者需要交互项检验：以方法 × 任务为两因子，检验交互效应是否显著。

两者的区别是可构造的，且要分清两种情形。

**情形一（交互项不显著而逐任务效应量不同）**：两个任务上 A−B 的效应量都为正、都显著，但两者之差（即交互项）的置信区间跨零。此时逐任务看是「两边都显著、方向相同」，交互项却不显著 —— 不能声称任务依赖，只能说效应量存在点估计上的差别。

**情形二（交互项显著而逐任务看不出异常）**：两个任务上 A−B 的效应量方向相反、各自都显著。此时逐任务看两边都「有效果」，交互项却显著 —— 可以声称任务依赖。

注意不能写成「都不可区分于零却一个显著一个不显著」：置信区间跨零就是两边都不显著，那种描述自相矛盾。

所以 Chomicz 2024 的数据支持的只是**范围限定**：结构方法在其考察的表位制图基准上有优势，该结论不自动推广到 binder 检测。它不构成「排名反转」的证据。

这收窄了 §1 的那条结论。原条文写的是「排名随任务变化」，并给了两个任务各自的结论；这条说那个表述需要交互检验才能成立，目前只有范围限定这一较弱形式。

可操作要求：凡是引用 Chomicz 支持「任务依赖」的地方，报告方法 × 任务的交互项及其置信区间，或明确降级为范围限定。

可证伪内容：若交互项显著且方向与逐任务结论一致，则范围限定可以升级为真正的任务依赖，§1 原表述恢复。
