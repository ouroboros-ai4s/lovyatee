# Predicted Epitope Field Is A Reference Panel Marginal

## description

抗原通用表位预测器的输出不能作为任何一个抗体–抗原对的表位观测。它是参考抗体集合上的并集，划分信息已经在取并集时丢掉了。

六条的输入输出各不相同：BepiPred-2.0 要抗原序列，BepiPred-3.0 要序列加蛋白语言模型表示，DiscoTope-3.0 要抗原结构与逆折叠潜表示，PEPITO 要结构加多距离阈值与半球暴露，CEP、SEMA 同理。但标签是同一形式：残基 r 为正，当且仅当参考复合物集中**存在某个**抗体 a 使 d(r, a) < cutoff。这是对参考抗体集取 ∃ 的并集，输出近似 P(∃a 接触 r | 抗原)，而不是 P(r 接触给定 a | 抗原, a)。

反例（我构造）：某抗原表面有互不相邻的 patch A、B、C。参考配置一为两条抗体分别结合 A 与 B；配置二为一条抗体横跨 A∪B。两种配置的并集逐残基完全相同，任何以并集为标签的模型给出相同分数场，但前者是 2 个表位、后者是 1 个。**丢的是划分信息，不是精度 —— 提高 AUC 不会恢复它。**

对照第 24 条 EpiScan：它按「抗体特异性表位」建模，输入含 VH/VL/CDR/FR 分块，是本节唯一尝试给 (抗原, 抗体) 条件量的条目。边界由此划出：单侧输入给边缘量，配对输入才可能给配对量。

后果（推论，标为待检验假设）：标签并集由参考复合物集决定，「抗原 X 的预测表位图」实质是参考抗体分布投影到 X。对参考集未覆盖的抗原 —— 正是 (a) 要新收的那批 —— 该投影无定义。所以用预测器给纯序列数据补表位，补出来的是抗原的**潜在表位先验**，与抗体无关；多样性要量的是这批抗体的表位观测，两者不是同一个量。

具体构造（可复算，不需要新实验）：抗原表面有互不相邻的 patch A、B、C，每个 patch 5 个残基。配置一：抗体 a₁ 的足迹 = A，a₂ = B。配置二：a₃ 的足迹 = A∪B。两者的并集都是 A∪B（10 个残基），逐残基完全相同。但配置一是 2 个表位、配置二是 1 个。任何以并集为标签的模型对这两种配置给出同一个分数场，所以它无法区分这两者 —— 这不是精度不足，是信息在标签构造时已经被商掉了。

可操作要求：引用任何抗原通用表位预测器时，必须同时报 (a) 它的参考抗体集是什么、规模多大、如何从参考复合物集构造标签（∃-并集还是配对）；(b) 所报数值是「该抗原的潜在表位先验」还是「这批抗体的表位观测」。缺任一项时，该数值不能用于表位覆盖统计，只能记为抗原侧先验。

本条没有排除任何具名替代解释 —— 「并集标签在足够大的参考抗体集下会逼近配对量」这一读法未被反驳，因为「足够大」没有定义。这是本条目前的一个缺口。

可证伪内容：若某个以并集为标签的预测器在留出抗原上，对同并集的两个参考配置给出可区分且可复现的不同分数场，则并集不可逆的论证被否证。
