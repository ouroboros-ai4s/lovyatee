# Epitope Object Choice Can Flip Panel Rankings

## time

2026-10-21

## lineage

- [[epitope_partitions_are_not_axiomatically_nested]]: 五种测量对象互不嵌套，跨论文比较须先固定对象。
- [[epitope_diversity_rankings_depend_on_weighting]]: 声明阶数 q 与权重 w 是两个正交自由度。
- [[footprint_overlap_does_not_predict_escape_spectrum]]: 提供「接触划分与逃逸谱划分可以解耦」的经验支撑，本条的构造依赖这一解耦。

## relation

## description

两条父记录各自说了一件事：跨论文比较要先固定测量对象；排序依赖阶数 q 与权重 w。合起来会得到一个父记录都没说的结论：**对象轴位于 (q, w) 之外，对 q 与 w 的稳健性扫描看不见它。**

两个 panel 各 12 条抗体，同一 τ、同一 linkage，只换测量对象：

| | 接触残基划分 | 逃逸谱划分 |
| --- | --- | --- |
| panel P1 | 2 簇，各 6 条 | 1 组，12 条 |
| panel P2 | 1 簇，12 条 | 4 组，9 / 1 / 1 / 1 |

按 Hill 有效数算，三档阶数：

| 阶数 | 接触：P1 / P2 | 逃逸谱：P1 / P2 | 接触判读 | 逃逸判读 |
| --- | --- | --- | --- | --- |
| q = 0 | 2 / 1 | 1 / 4 | P1 更多样 | P2 更多样 |
| q = 1 | 2.000 / 1.000 | 1.000 / 2.309 | P1 | P2 |
| q = 2 | 2.000 / 1.000 | 1.000 / 1.714 | P1 | P2 |

算法（可直接复算）：P1 接触 (6/12)² × 2 = 0.5，逆 Simpson 1/0.5 = 2.000；P1 单组，三档全为 1。P2 接触单组，三档全为 1。P2 逃逸 (9/12, 1/12, 1/12, 1/12)：q=1 时 exp(−(0.75·ln0.75 + 3×0.0833·ln0.0833)) = exp(0.8370) ≈ 2.309；q=2 时 Σp² = 0.5625 + 3×0.00694 = 0.5833，逆 Simpson = 1.714。

**关键在这一处：排序在每一档 q 上都稳定，但只在对象之间翻转。** 在接触对象下，P1 > P2，三档 q 一致；在逃逸谱对象下，P2 > P1，三档 q 也一致。所以一份标准的稳健性报告（固定对象、扫 q 与 w）会给出「排序对阶数稳健、对权重稳健」的结论，而排序的真正来源在它扫描的轴之外。

**这是父记录都没有的一步。** [[epitope_diversity_rankings_depend_on_weighting]] 说 q 与 w 正交，那条的正确用法是固定 q 扫 w。对象轴不是这样：换对象换掉的是划分本身，不是一个划分上的重新加权。因此不存在任何 (q, w) 组合可以复原另一个对象下的排序，也不能把两个对象的结果按某个权重平均 —— 它们不是同一个量的两个估计，是两个量。

**构造的可实现性**：P2 的「接触一簇、逃逸四组」依赖 [[footprint_overlap_does_not_predict_escape_spectrum]] 已记入池内的经验事实 —— 足迹相同的抗体可以有不同逃逸谱。P1 是反向情形：接触不同而逃逸谱相同。两者都不是凭空构造，且不需要新数据。

**可操作后果**：一份只做 q ∈ {0,1,2} 与两种权重扫描的稳健性检查，覆盖的是对象固定后的那一小块。正确写法是：固定对象后扫 q 与 w，并**同时报出至少第二个对象下的排序**。若两个对象下的排序不同，则该比较不成立 —— 不是「稳健性不足」，而是「这两个数据在同一问题上不可比」。这与 [[diversity_reports_need_three_independent_field_classes]] 属于同一条要求的两个层面：那条说三组字段缺一不可，本条给出「缺了会怎样」的最强形式 —— 不是数字变了，是排序反了。

条件方向：**必要**是固定测量对象后才能谈跨 panel 排序 —— 上表给出同一批数据在两个对象下方向相反的直接构造。**不充分**是附上第二个对象也不够：若两个对象给出不同排名，没有任何规则能裁定哪个正确，只能声明本次比较采用哪个对象、以及为什么。

可证伪内容：若存在一类 panel，其按接触残基与按逃逸谱给出的划分在 q ∈ {0,1,2} 上诱导出**完全相同**的跨 panel 排序（秩相关为 1 且无并列），则对象轴在该类 panel 上退化为 q 轴的重复，本条对该类失效。

边界：若两个对象在同一抗体集合上诱导的划分恰好相同（父记录已声明这是该 panel 的经验事实），则对象轴无差异，本条不适用。上表的翻转依赖「接触划分与逃逸划分解耦」，两者高度相关时构造不成立。
