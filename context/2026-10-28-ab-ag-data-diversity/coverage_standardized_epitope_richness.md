## description

原始丰富度（簇数）依赖样本量：1,909 条 VHH 与 200 条抗体两个数据集，即使表位构成完全相同，前者也必然报出更多簇。这就是跨数据集多样性比较在实践上不可做的直接原因。

生态学的解是把样本抽稀到固定覆盖度再计数，而不是抽稀到固定样本量。Good's coverage 估计 C = 1 - f1/n（f1 为单例数），rarefaction / extrapolation 曲线给出任意参考样本量下期望的丰富度。三者组合后，不同规模的 panel 可以在同一覆盖度或同一参考样本量上比较。

迁移到表位需要三个前提，缺一不可：

1. 类别是表位簇，不是抗体 —— 因此必须先固定 τ 与 linkage，否则「物种」本身在变；
2. 抽样单位是抗体记录，且记录之间独立（同一 B 细胞克隆的多个变体不是独立抽样）；
3. 观测协议可比 —— 竞争测定、逃逸谱、结构接触三者的漏检率不同，混在同一曲线里没有意义。

满足前提时，这个量回答的是「这批数据覆盖了该抗原表位空间的多少比例」，而不是「有几个表位」。前者才是下游决策（要不要继续收集）需要的量。

未解决：表位簇的「物种」定义依赖阈值，而抽稀理论假定物种身份固定。这个不一致没有现成解 —— 一个折中是固定 linkage、对 τ 做抽稀曲线族，报告 τ 敏感度而不是单一曲线。
