# Canonical Class Count Is Not A Dynamical State Count

## description

Fernández-Quintero 2020 报告：若干规范簇的中位数实际属于同一个动力学极小。若成立，则**簇 → 动力学盆地的映射不是单射**，规范类数不是动力学状态数的忠实计数 —— 它偏多。

这与 [[cdr_class_map_is_not_a_function_in_either_direction]] 的成员不稳定是两件不同的事：

- 那条说一个序列可以属于多个类（映射的**反方向**多值）；
- 这条说多个类对应同一个状态（映射的**正方向**多对一）。

两者的后果方向相反。前者使指派计数不可定义，后者使类数系统性偏高。所以「CDR 结构有多少种状态」不能直接用类数回答，也不能用「跃迁频繁」推出类数偏高 —— 必须做盆地合并。

可证伪内容：在同时有 MD 轨迹与结构分类的数据集上，建立簇 → 盆地的对应表。若该表是单射，则这条被推翻，类数可作状态数的下界使用。

具体可做的检验（FQ 2020 的数据可复用）：对每一个规范簇，算其成员轨迹在马尔可夫状态模型里的驻留盆地；若两个簇的成员主盆地相同且驻留分布重叠过半，即判为合并。构建性反例是现成的 —— 只要找到一对这样的簇，非单射即成立；反之若所有簇对的主盆地互不相同，本条被推翻。

条件方向要分开。**必要**：用类数回答状态数，必须证明簇 → 盆地的对应是单射 —— 这是本条的核心否证。**不充分**：即使是非单射，「类数偏高」的量级（偏多几倍）也未被本条给出，所以它只否定「类数 = 状态数」，不给出可用的换算系数。

边界：只在做过动力学分析的体系上有证据。对绝大多数只有晶体结构的体系，该映射完全没有测量过，此时类数与状态数的关系未知，不是「相等」也不是「偏高」。

实操：这条限制的是「把 PyIgClassify 这类库里的类计数当作结构多样性的量」。它们的类计数是结构坐标空间的聚类结果，没有动力学依据。

排除的替代解释：类数偏多会不会只是「测得多所以分得细」的采样效应（样本量越大类越多）？不能排除，但两者方向可区分 —— 采样效应使类数随 n 单调上升且无平台，而盆地合并给出的偏多是结构性的、在 n 固定时也存在。要看后者，必须固定 n 再比。
