# Design Pipeline Success Does Not Establish Fingerprint Sufficiency

## time

2026-10-21

## lineage

## relation

## description

Gainza 2023 用 MaSIF 表面指纹设计 de novo binder，多个设计获实验验证；综述把它读作「表面指纹足以编码识别特异性」的反向证明。已报告的是整条流水线可行。**我加的限制是**：它没有单独排除下游步骤补足指纹信息的解释。

反例是构造性的：即使指纹对两个目标 patch 没有区分，下游的结构筛选与实验验证仍可能区分它们，并产出成功设计。所以流水线成功与指纹独立充分是两个命题。

要拆开这两个命题，需要一个能单独变化指纹的对照。可行的设计是**指纹消融**：保持下游筛选与实验验证完全不变，只把界面表示换成随机投影或常数表示，再跑同样预算的设计。若成功率显著下降，说明指纹确实在这个任务上贡献了信息；若成功率不变，说明贡献来自下游。原文（Gainza 2023）没有做这个对照 —— 它的设计里指纹与下游是一起被验证的，所以「充分性已建立」这一读法缺少的就是这一步。

这一步之所以能判，是因为它只改一个因子；而成功率本身是两个因子的联合效应，无法从联合值反推单项贡献。

条件方向：**必要**是把指纹的判定力用假合并率与假拆分率单独测出来，这是把「流水线成功」与「指纹充分」分开的唯一手段。**不充分**是即使两个错误率都低，也只能说指纹在留出 patch 对上可用，不推出它对未见过的界面类型也充分。

从成功也读不出第二个更强的东西：区分能力不等于距离校准。指纹能把 A、B 分开，不推出 d(A,B) 与功能差异成比例，也不推出距离小意味着数据冗余。

可操作要求：把界面去重建立在 MaSIF 表示上之前，固定编码器版本与读出规则，在独立标注的 patch 对上单独测假合并率与假拆分率，且读出环节不得额外访问原始坐标。整条流水线的成功率不能替代这项检验。

可证伪内容：若仅用固定指纹的判定器、在预先声明的留出集上使两类错误率的置信上界均低于预定容限，则「充分性未验证」在该任务上撤回。
