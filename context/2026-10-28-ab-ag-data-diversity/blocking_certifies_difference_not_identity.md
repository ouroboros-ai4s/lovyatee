# Blocking Certifies Difference Not Identity

## description

Abdiche 2014 在阵列式无标记生物传感器上做交叉阻断，原文明确写出：两抗体交叉阻断是「结合同一表位」的**必要非充分**条件。方向不可反 —— 不阻断 ⇒ 不同表位；阻断 ⇏ 同一表位。这是分箱文献的方法论结论，不是该文的实验发现。

把这句话拆成两个方向相反的失效，才看得出它对数据多样性估计做了什么。

**充分性失效（合并，有符号）。** 一个 bin 是阻断图的连通分量，而阻断不传递：A 与 C 可以同时结合，即使二者都与 B 的足迹重叠。所以连通分量只能合并、不能拆分，bins 数 ≤ 该 panel 上可分辨的表位数。在固定 panel 上补测更多对只会加边，分量数单调不增 —— 这个方向的误差是可预测的，且不随测定多做而消失。

**必要性失效（拆分，须标定）。** 同表位的两个抗体可能因为亲和力差、单价结合状态或别构而测不出阻断，此时它们被分进不同 bin，观测表位数偏高。Kot 2025 用 DMS 与 SPR 分箱联合，合取两个必要非充分条件让「同一」更难被认证 —— 假阴性率相乘，方向不变。

原文「分析的抗体对数越多，区分表位概率越高」是概率陈述，没有区分「加大 panel」与「同一 panel 多测对」，而这两种读法的图论后果相反：前者可能拆开分量，后者绝不会。所以报告分箱结果必须同时给出 panel 构成与实测对集合，只给 bins 数不可复现。

对下游：分箱只能证不同，不能证相同。用分箱数据支撑「现有抗体数据已高度重复」，方向恰好用反了 —— 冗余判定的阳性证据必须另换协议。

与 [[epitope_community_count_is_assay_resolution_limited]] 的关系：那条说社区数误差无固定符号；本条在成对阻断这一具体协议里，把误差分解成结构性合并（有符号、单调）与测定假阴性（拆分、须标定）两部分，是那条的细化而非复述。

可证伪内容：在完整阻断矩阵上出现 A 阻断 B、B 阻断 C、而 A 不阻断 C 的三元组（即阻断在这一 panel 上传递），则本条的结构性合并机制不成立。
