## description

表位多样性通常是点估计（一个簇数、一个熵值），而点估计不携带「这次划分有多可靠」的信息。bootstrap 重采样只反映既有采样支持内、给定聚类规则下的不确定性，不能揭示从未采到的结合模式 —— 这是它的上下界，不是它的用途。

可执行的替代：以真实独立采样单位（供体 / B 细胞克隆 / 独立实验，而不是同一实验内的抗体）为重采样单位，在 (τ, linkage) 网格上重采样，统计每个簇在多大比例的重采样下仍然分开，报告「在 ≥ x% 重采样下仍独立的簇数」作为多样性计数。

这个量随 x 单调，且能区分「稳定存在的少数模式」与「恰好被 τ 切开的连续分布」——后者在重采样下迅速合并。

注意两点边界：

1. 稳定性高不等于生物学饱和，只说明在当前 panel 与规则下可复现。未观测模式的不确定性必须单列，不能由 bootstrap 覆盖。
2. 重采样单位若不是独立采样单位（例如把同一实验的抗体当作独立），bootstrap 会系统性低估方差，这条退化成一个假的置信区间。
