# Single Linkage Bridges Distinct Clones

## description

单连锁在阈值 τ 下取的是阈值邻接关系的**连通分量**。这是一个定义性质，不需要分布假设。

由它可得一个显式构造：设组 A 与组 B 各含大量成员，组内距离都小于 τ，组间最小距离大于 τ，但存在一条中间序列 m，使 d(a, m) < τ 且 d(m, b) < τ（a ∈ A, b ∈ B）。则单连锁把 A ∪ {m} ∪ B 并成一个连通分量，而完整连锁在同样的距离与阈值下保持 A、B 分离。

所以：**链式桥接是单连锁产生额外合并的一种机制。** 只主张这一条，不主张它是克隆数对 τ 敏感的唯一解释。

两个必须加的限定：

1. **「两个真实克隆」需外部谱系真值。** 上面的构造只说明距离结构产生合并，不说明合并前的 A、B 真的是两个克隆 —— 这必须由 germline 与谱系信息独立确认，不能由距离构造自证。否则命题退化成同义反复。
2. 两点情形不经过桥接：若只有两个序列、距离为 d，τ 跨过 d 时单连锁与完整连锁都会从两组变成一组，没有中间序列。所以桥接是**额外**合并的来源，不是阈值的全部敏感性。

对数据收集的含义：克隆数与「实际有多少独立谱系」的差距不是噪声，是连锁方式决定的系统偏差，方向固定（单连锁偏少）。这与 [[contact_overlap_is_a_tolerance_not_an_equivalence]] 的结构同构 —— 阈值邻接是容差关系，连通分量把它**确定化**成等价类，代价就是这个方向固定的合并偏差。
