## description

残基编号是各抗原自己的命名空间。抗原 A 的「残基 10」与抗原 B 的「残基 10」之间没有接触同一性，所以把两个接触残基编号集合直接求交，得到的是一个关于编号方式的偶然事实，不是关于结合面的陈述。换一套编号，交集就变。

那批宣称「无需序列对齐」的方法不是取消了对应问题，而是换了一种方式给出对应：iAlign 用界面几何对齐，ProBiS 用局部结构比对，PPI-Surfer 用表面 patch 的理化描述子。三者产出的距离属于「局部签名距离」这一测量对象；它们可以在映射建立之后重算接触重叠，但映射本身必须留档，否则重算出来的数不可复核。

具体实例（我构造，可复算）：抗原 A 的接触残基为 {10, 11, 12}，抗原 B 为 {10, 12, 14}。直接求交得 {10, 12}，Jaccard = 2/4 = 0.5。若把 B 的编号整体加一（结构完全不变，只换编号命名），B 变成 {11, 13, 15}，与 A 的交集是 {11}，Jaccard = 1/5 = 0.2。同一个结构对、同一套接触，只换命名，重叠从 0.5 掉到 0.2。这就是「关于编号方式的偶然事实」的可复算形式。

条件方向：**必要**是声明映射，否则该比较记为未定义（不是低相似）—— 由上面的构造直接给出。**不充分**是即使声明了映射，不同方法给出的对应关系不同（几何对齐 vs 局部结构比对 vs patch 描述子），由此得到的重叠仍是方法相关的量；所以「有映射就可比」不成立，映射来源必须随数值一起报告。

可操作要求：跨抗原比较接触残基集合之前，声明映射来源、允许的对应关系、未匹配残基如何处理、归一化用哪个分母。缺映射时该比较记为未定义，不记为低相似。

可证伪内容：若能给出一种算法，直接对两个独立的局部编号求交，且在任意独立重编号下仍恢复同一个跨抗原接触重叠，则这条被推翻。
