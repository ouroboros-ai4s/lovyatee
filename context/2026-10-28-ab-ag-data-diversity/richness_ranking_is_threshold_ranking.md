## description

τ 与 linkage 未固定时，跨数据集按 q=0（簇数）排出的次序，排的主要是聚类阈值的差异，不是数据的差异。

支撑是 Hill 数 D_q = (Σ p_i^q)^{1/(1−q)} 对簇数变化的敏感度随 q 单调下降。可构造的对照（我构造，非原文数据）：一个 100 条记录的簇被 τ 切成 99 / 1 两个簇 —— q=0 从 1 变 2（+100%），q=1 从 1 变 exp(0.0560) ≈ 1.058（+5.8%），q=2 从 1 变 1/0.9802 ≈ 1.020（+2.0%）。同一次聚类操作，三个阶数分别放大 100%、5.8%、2.0%。

所以「哪个数据源更多样」在 q=0 上主要由 τ 决定，而 τ 通常由数据生产方选定，不是被比较对象的内在属性。同一份数据换一家机构聚类，排序可以翻转。

与 [[epitope_diversity_rankings_depend_on_weighting]] 的分工：那条已声明阶数 q 与权重 w 是两个正交自由度，但只展开了 w（各类算多重）；本条展开 q（稀有类算不算数），并给出它与 τ 的耦合 —— 这是那条没有的内容。

可操作要求：跨数据集报多样性必须同时给 q、τ、linkage。只报 q=0 的数只能读作「该数据集在自身聚类下的簇数」，不能进排序。要排序，报 q=1 与 q=2 两档，并在 τ 的 ±20% 上检验排序稳定性。

边界：若被比较的数据集共享同一份簇定义（同一 τ、同一 linkage、同一实现），τ 项抵消，q=0 可用。

可证伪内容：在同一批数据上取 τ ±20%，若 q=0 的跨数据集排序在区间内不变、且与 q=2 的排序一致，则本条对该批数据不成立。
