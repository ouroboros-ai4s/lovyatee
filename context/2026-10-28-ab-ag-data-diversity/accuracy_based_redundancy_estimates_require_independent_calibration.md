# Accuracy Based Redundancy Estimates Require Independent Calibration

## time

2026-10-21

## lineage

- ../bodn/2026-10-21-abag-diversity-as-evaluation-tool-survey-s4.md: 第 11 条（Bernett 2024 报告去泄漏后性能崩塌）提供问题背景；下面的混合公式与反演条件是我自己的推导，不是该文的实证结论。

## description

想从公开基准的准确率反推开放数据的重复比例，需要先固定三样：参考库、近邻匹配规则、测试总体。设 R 表示某个测试项存在合格的训练近邻，π = P(R=1)，a 与 b 分别是同一模型在 R=1 与 R=0 时的正确率。按全概率公式

  A = π·a + (1−π)·b，

只有在 a 与 b 已独立校准、可迁移到目标总体、且 a ≠ b 时，才有 π = (A−b)/(a−b)。a 与 b 接近时分母趋零，反演误差被急剧放大。

三条不能越的线。**分差不是 A−b** —— 两个划分之间的分数差同时含训练量、难度与暴露的变化，与这个反演无关。**AUC、F1 等非逐项均值指标不能代入**。**性能崩塌也不是「原分数全是近邻检索」的证明**，节点度捷径是第二解释，这正是 Bernett 的结论不能直接用的地方。

所以公开泄漏基准目前只能给出待校准的冗余线索，不能替代直接审计。合成数据可以用来检验反演公式、偏差与区间覆盖，但模拟成功与真实数据上的方法排序一致，都不认证真实 Ab-Ag 上的校准。

具体数值（我构造）：设 A = 0.80、b = 0.70，则 π = (0.80 − 0.70)/(a − 0.70)。a = 0.90 时 π = 0.10/0.20 = 0.50；a = 0.75 时 π = 0.10/0.05 = 2.0（越界，说明 a、b 太近）；a = 0.72 时 π = 5.0。同一个观测准确率，在 a 的 ±0.15 不确定范围内，反推的冗余比例可以从 50% 走到不可用。

条件方向：**必要**是分别校准 a 与 b 并保证 a ≠ b —— 由上面的数值直接给出。**不充分**是即使 a、b 都校准好，π 的估计仍依赖「测试总体可迁移」这一前提。

可证伪内容：冻结 a、b 后，在独立目标样本上估得的 π 与直接审计得到的比例之差，其 95% 置信区间完全超出 ±0.05，则这次校准迁移被否证。
