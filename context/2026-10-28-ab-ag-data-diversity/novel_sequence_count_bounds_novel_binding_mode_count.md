## description

固定一个单值映射 φ: 序列 → 结合模式（即每个序列只对应一个模式）。则新增模式与新增序列满足

|φ(S_new) \ φ(S_old)| ≤ |S_new \ S_old|

这是像集计数的构造性结论：φ(S_new \ S_old) 的每个元素至少被 S_new \ S_old 中的一个元素原像，故基数不大于后者。不是经验概括，不需要数据。

因此「按序列去重得到的新颖度」不会低于「按结合模式去重得到的新颖度」—— 在**绝对计数**意义下。两个限定必须同时写：

1. **只能是绝对计数。** 比例形式不成立。反例：原有 100 条序列全对应模式 A，新增 1 条序列对应 B，新增序列占比 1/101，新增模式占比 1/2。比例的相对关系与绝对计数相反。
2. **φ 单值这个前提可能失效。** 交叉反应抗体映到集合而非单点，此时 S_new \ S_old 的像可以是多个模式，且这些模式可能不在 φ(S_old) 里。所以这定理是一次**条件定理**，条件失效时不适用。

这给出了一个方向性结论，与 [[sequence_diversity_bias_has_no_fixed_sign]] 不同：那条说的是两个表示下的多样性量无固定偏差方向，这条说的是两个量之间的**跨表示计数**有固定不等式。两者不矛盾，因为对象不同。

实用后果：公共性（Briney 2019）与测序错误造出的单例，都只作用在这个不等式的松弛侧，不构成反例。它们使左边远小于右边，而不是相反。

边界：不能由此推出「序列去重一定高估表位多样性多少」—— 差值可以是零。要有量级，必须实测 φ(S_new \ S_old) 的大小。

竞争解释要排除：新增序列与新增模式的比例差异，也可能只是「新序列大多落在已有模式上」的采样效应，而不是两个计数量的结构性差别。这条排除它的方式是条件——不等式对**任意** φ 与任意 S_old、S_new 成立，不依赖采样过程；采样效应会改变差值大小，不会改变符号。
