# Contact Overlap Is A Tolerance Not An Equivalence

## description

阈值化接触残基重叠（Jaccard > τ、共有接触残基 ≥ k 等）只满足自反与对称，不满足传递性。

几何上平凡可构造反例：B1 与 B2 各覆盖同一表面 patch 的一半且互补重叠，B2 与 B3 同理，B1 与 B3 不重叠。此时三个抗体在阈值下两两相邻，簇数为 1 或 2 取决于成簇规则 —— 单链接（连通分量）把三个并成一簇，全链接拆成三簇。

更强的一步：加入一个连接两簇的抗体，单链接的簇数可以从 2 降到 1。所以簇数不是 panel 的函数，而是 f(panel, τ, linkage)。

结论不是「要选对 linkage」，而是：任何报告的表位簇数必须同时报告 τ 与 linkage；不报告时该数字不可复现。这一条同时否决了把「表位数」当成抗原固有量的用法。

具体数值（我构造，可复算）：三个抗体，接触集合各 100 个残基，取
B1 = {1…100}，B2 = {51…150}，B3 = {151…250}。
|B1∩B2| = 50，|B1∪B2| = 150，Jaccard = 50/150 ≈ 0.333；
|B2∩B3| = 50，Jaccard ≈ 0.333；
|B1∩B3| = 0，Jaccard = 0。
取 τ = 0.3：0.333 > 0.3 而 0 < 0.3，故 B1—B2—B3 是一条链。单链接（连通分量）给 1 簇；全链接要求簇内两两相邻，B1 与 B3 不相邻，故给 3 簇。同一个 panel、同一个 τ，簇数从 1 走到 3。

（此前的 75 残基版本不可实现：|B1|=|B2|=|B3|=75 且 B1∩B3=∅ 时，|B2| 至少要有 |B2∩B1|+|B2∩B3| = 100 个元素，与其 75 矛盾。）

条件方向：**必要**是同时报告 τ 与 linkage —— 上面的构造直接给出（同一 panel、同一 τ，两种 linkage 给 1 与 3）。**不充分**是即使报全了两者，簇数仍不是 panel 的固有属性，只是 f(panel, τ, linkage) 的一个取值；可判的方式是换一个 τ 重算，若簇数随之变而 panel 未变，则「簇数 = 表位数」的读法在第二个 τ 上同样失效。

可证伪内容：对任一给定 panel，存在 τ 区间使单链接与全链接给出不同的簇数 —— 可直接计算验证，无需实验。
