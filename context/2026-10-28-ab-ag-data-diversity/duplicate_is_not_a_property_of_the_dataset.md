## description

前两条父记录各削弱了「重复率是数据的属性」这一读法的一半：参考库是声明，联合判定不能拆成两次单侧判定。第三条把这件事推到底 —— **对非单射的测量，冗余不是「依赖参考库」，是根本没有取值。**

理由是纯构造的。冗余判定的形式是「本记录相对参考集是否存在合格匹配」。要做到这一点，被比较的对象必须是确定的个体：给定记录，能说出它与哪一条参考相同或不同。血浆逃逸谱不满足这个要求 —— 不同的成分集合与权重给出逐位点完全相同的谱（父记录已给构造：A=(1,0)、B=(0,1)、C=(0.5,0.5)，权重 (0.5,0.5,0) 与 (0,0,1) 都给 (0.5,0.5)）。所以一条血浆记录在抗体级参考库前的最近邻是未定义的：它的原像是一个集合，不是一个点。

这比「参考库必须声明」强一档，两者不可互相替代。

- 参考库声明不清 → 冗余值**有**，但随参考库变。
- 测量非单射 → 冗余值**无**，且在任何一个参考库下都无。

把两者混为一谈会产生一个具体的错误：审计时把血浆记录与抗体级数据放进同一张表，对前者也报一个冗余率。那个数不是「不准」，是「没有对象」。它通常会被算成「不重复」（因为混合物与任何单条抗体都不接近），而虚增方式恰好是让现有数据看起来更不重复 —— 这个方向偏差在 [[polyclonal_escape_profiles_are_mixture_measurements]] 里已被记为分母污染，本条给出它的判定论根源。

**由此得到的操作判据**：冗余率的报告对象必须是**确定个体**。若测量对成分非单射，该记录只能进入「成分未知的混合记录」这一类，不参与冗余率的分母，也不参与分子。要把它纳入，须先把原像缩到单点（例如按已知成分做去除/重建实验），此时它转化为一组确定性记录。

与 [[redundancy_undecidability_splits_into_computational_and_observational]] 的关系要写清，因为两者都产出「不可判」：那条的不可判是**可归约的**（更多算力或更多标注），本条的不可判是**不可归约的** —— 再多数据也不会让一个非单射映射变成单射。所以这构成第三种未决，与前两种并列：

| 未决类型 | 来源 | 补救 |
| --- | --- | --- |
| 计算性 | 未解到最优 | 更紧的松弛、更多算力 |
| 观测性 | 阈值未标定 | 带标注的候选集 |
| **表征性**（本条） | 测量非单射 | 无。只能换测量或缩原像 |

条件方向：**必要**是先在测量层面确认单射性，再谈冗余 —— 非单射测量下的冗余值没有对象，这是本条的直接结论。**不充分**是即使测量单射，冗余仍依赖参考库与判定规则（前两条父记录），所以「单射了就得到客观冗余率」不成立。

可证伪内容：若对一组已知成分的血浆混合物，由其逃逸谱反推的成分构成在留出个体上逐条复现（预测的谱变化与实测一致，且原像唯一），则非单射性被推翻，本条对血浆记录失效。

边界：测量对象本身就是混合物层面时（例如「这批血浆覆盖了多少个逃逸模式」），冗余判定的个体是血浆记录本身，单射性不是必要条件，本条不适用。
