## description

Greaney 2021 把深度突变扫描的逃逸制图推广到多克隆人血浆，报告两点：不同个体在主导识别的抗原位点上存在变异；**血浆逃逸谱不唯一重构其组成抗体的特异性**。

形式化（我写的，非原文）：血浆逃逸谱 = f(成分抗体集合, 各成分权重与亲和力, 测定阈值)，f 非单射。多个成分组合给出同一谱，所以这是**可识别性**失效，不是分辨率不足 —— 加测序深度、加稀释梯度都补不回来。这一点必须与「信号弱、测不准」区分开：前者是原理性的，后者是技术性的。

同族第二条：抗原制图显示血清 panel 的选择会改变推断出的抗原空间（第 38 条，无 URL，仅作存在性证据）。

后果落在计数单位上。一条血浆记录是「一个混合样本的一次观测」，不是 N 条抗体观测。审计现有数据重复率时，把血清学面板与抗体级数据放进同一分母会虚增分母 —— 而虚增的方向是「看起来重复更少」，这会低估现有数据的冗余度，恰好偏向「还得再收」。同理，(a) 的抗体–抗原对数配额不能把血浆记录折算成抗体数。广度还随抗原 panel 与价态变化，见 [[cross_reactivity_breadth_is_not_a_function_of_the_antibody_alone]]。

与 [[antibody_diversity_counting_unit_is_declared_not_derived]] 的关系：那条说四个计数单位之间不存在固定换算；本条指出其中有一个单位与抗体级单位之间的换算**在原理上不存在**（非单射），比「未声明」更强。

具体实例（我构造，可复算）：两个位点、三种成分。成分谱为
A = (1.0, 0.0)、B = (0.0, 1.0)、C = (0.5, 0.5)，
混合权重取 (0.5, 0.5, 0)。则混合谱 = 0.5·(1,0) + 0.5·(0,1) = (0.5, 0.5)。
再取权重 (0, 0, 1)：混合谱 = 1·(0.5,0.5) = (0.5, 0.5)。
两组**不同的成分集合与权重**给出逐位点完全相同的谱，所以从谱无法反推成分构成 —— 这就是 f 非单射的一个具体构造。注意关键在两组输入确实相异：第一组是两个纯抗体各半，第二组是单一混合特异性抗体，它们在任何抗体级统计里都应被算作不同的东西。

条件方向：**必要**是把血浆记录与抗体记录分入不同计数单位（否则分母被虚增），这是本条的直接后果。**不充分**是即使分了单位，「一个血浆记录代表多少条独立抗体」仍然未知；所以分开计数解决了分母污染，没有解决权重估计。

可证伪内容：在同一血浆上按已知成分做去除/重建实验，由逃逸谱反推的成分特异性在留出个体上可复现（预测的谱变化与实测一致），则非可逆性被推翻。
