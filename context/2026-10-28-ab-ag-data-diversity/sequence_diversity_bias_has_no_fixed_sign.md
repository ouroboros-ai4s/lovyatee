# Sequence Diversity Bias Has No Fixed Sign

## description

「序列多样性比结构多样性高还是低」在文献里有三种方向相反的结论：

- Robinson 2021：结构聚类下 92% 的抗体结合同一域 → 序列**高估**表位多样性；
- Mitchell & Colwell 2018：VHH 的 paratope 在骨架片段、接触残基、接触类型上都更多样 → 与常规抗体混池**低估** VHH 一侧；
- Wong 2021 / Waury 2025：多数情况下序列相似性（克隆分型）已足够识别同一表位，只在困难子集上失效。

三者不矛盾，是同一个量在不同区间的不同符号。所以问「偏差方向是什么」而不声明区间，是没有答案的问题。

可测量：在匹配的 τ 与同一 panel 上定义 R = D_struct / D_seq（两者都可用 Hill 有效数，q 需固定）。R < 1 表示序列高估、R > 1 表示序列低估。

可证伪内容：R 是双侧效应，且两效应在混池中会互相抵消，所以**合并池上的 R 不可解释**。检验方式是按抗体 format 分层（VHH / 常规 VH-VL），再按抗原分层（单显性模式 vs 多域），若 R-1 的符号随这两层系统翻转，则符号不恒定成立。

反面：若 R-1 在分层后仍保持同号，则符号是恒定的，这条被推翻，改为「序列多样性相对结构多样性存在固定方向的偏差」。

注意：R 的分子分母都必须用同一相似性度量族的两端，不能一边用接触残基 Jaccard、一边用序列同一性 —— 那样 R 度量的是两个度量的差，不是两种表示的信息差。

具体构造（我构造，可直接复算）：R 是比值，混池后的 R 由两层的 D_struct 与 D_seq 合并后再相除，**不是**层间 R−1 的加权平均 —— Hill 有效数不是线性量，合并会多出一个组间项。所以不能给出一个「加权得到 +0.02」的算式。能给出的是定性形式：两层的 R−1 异号时，合并后的 R 落在两者之间，可能接近 1；此时单看合并值会读成「偏差可忽略」，分层后才知道两层偏差都很大。要把这变成数值，必须先固定 q、两层的 D_struct 与 D_seq 各自取值，并说明合并方式（是逐个合并记录再算，还是层内各算再按什么权重汇总）—— 这一步本条不做，因为 R 的定义本身还缺「合并算子」。

条件方向要分开。**必要**：在报任何 R 之前，必须固定 q、τ 与相似性度量族，并声明按 format 与抗原分层 —— 因为同一批数据在不同层里可以给出相反的符号，不声明就无法解释任一个 R（上面的构造给出的正是这种抵消）。**不充分**：即使全部声明，R 的符号仍依赖层的划分粒度；分得越细，异号层越多，合并值越接近 1。所以「声明了分层就能得到唯一符号」不成立 —— 本条的正确结论是「符号是区间依存的」，而不是「给定分层后符号唯一」。
