# Peptide Library Data Cannot Be Pooled Into Conformational Coverage

## description

VirScan（Xu 2015）用噬菌体展示的肽库做人群血清学画像；Li 2021 从 1,051 名患者构建线性表位图谱。两条指向同一件事：线性表位与构象表位是两套统计。

加强一步（我的表述，不是原文）：这不是灵敏度较低，而是对不连续表位类**结构性为零**。需要跨片段接触的表位无法在单条肽上呈现，提高通量、加深测序、扩大队列都不改变这一点。所以肽库数据支持线性表位多样性计数，对构象表位空间的观测数是 0 —— 不是一个漏检率较高的样本，而是一个零灵敏度的测量。

这违反 [[coverage_standardized_epitope_richness]] 的第三个前提（观测协议可比），且违反的方向是单侧的。把肽库数据与结构/竞争数据并进同一条覆盖曲线，会让构象侧的覆盖看起来比实际更缺，同时虚增线性侧的观测数。这不是随机误差能平均掉的偏差。

对两个决策的具体后果：对 (b)，若开放数据中肽库数据占相当比例，按条目数计入「表位观测」会同时虚增线性侧分母、错误归因构象侧缺口。对 (a)，用肽库数据估计「已采到多少构象表位」得到的覆盖率会系统性偏低，从而高估需要追加的抗原数。

可操作要求：任何表位覆盖统计必须按「线性 / 构象」分层，并声明每层的测量协议；跨层求和需先声明一个把两层合并的理由，而这个理由不能是「都算表位」。

可证伪内容：若某肽库测定在结构验证下复现出不连续表位（接触残基分处不同线性片段）且回收率与线性表位同量级，则「结构性为零」被推翻。

具体实例：RBD 上与 ACE2 接触的残基里，K417、L455、F486、Q493 分属不同的线性片段（K417 在环区，455/486/493 在受体结合基序上）。一条覆盖 455–460 的肽不可能呈现 417 的接触，所以在任何以单条肽为单位的测定里，「同一不连续表位」的观测数恒为零 —— 这不是估计，是构造上的不可能。

条件方向：**必要**是分层（线性 / 构象）声明，否则任何合并求和都掩盖了单侧的零。**不充分**是即使分了层，线性层内部的覆盖也仍受肽长度与重叠窗口限制；所以分层让偏差可归因，不让它消失。
