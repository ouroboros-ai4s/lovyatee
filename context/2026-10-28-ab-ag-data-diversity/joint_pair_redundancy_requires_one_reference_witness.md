# Joint Pair Redundancy Requires One Reference Witness

## time

2026-10-21

## relation

## description

联合配对冗余要求**同一条参考记录**同时满足抗体侧与抗原侧的条件。分别存在一个相似抗体、一个相似抗原，是「存在 j」与「存在 k」两个量词，不能换成「存在同一个 j」。

构造例：参考库只含 (Ab1, Ag1) 与 (Ab2, Ag2)，查询 (Ab1, Ag2) 的两侧实体都完全见过，但这一配对本身从未出现。两侧都暴露、配对仍新颖。

这是量词推导，不是 Park、PLINDER 或 SABLE 报告的实验结果。后果对本仓库的下游问题很直接：汇总开放数据的联合重复率时，必须在参考配对上求两侧条件的交集，保存共同命中的记录 ID；不能把两个独立最近邻的分数拼成一次匹配。拼接会**把组合新颖性误报成冗余，抬高「现有数据已经高度重复」的估计**。

共同见证也只认证所声明的联合相似规则，不自动证明界面等价或功能等价。若定义本来就是单侧暴露，就不该套这个判据。

可证伪内容：在完整参考库上穷举，某查询被判为联合命中而它的两侧合格记录 ID 集合交集为空，出现一例即否证该实现。
