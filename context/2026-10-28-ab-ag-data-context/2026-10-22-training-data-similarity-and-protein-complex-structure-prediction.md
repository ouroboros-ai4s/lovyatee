# 项目计划书｜训练数据相似性与蛋白质复合物结构预测的泛化能力和可靠性

**研究对象：蛋白质复合物结构预测；首期聚焦由两条不同蛋白链组成的异源二聚体**  
**研究周期：8 周；第 4 周提交阶段报告**  
**编制日期：2026 年 10 月 22 日**

## 一、研究目标与总体设计

本项目以蛋白质复合物结构预测为对象，研究待预测复合物与训练样本的相似程度，重点回答两项核心问题：**哪些相似性有助于判断预测质量，以及依据这些相似性选择训练数据，能否改善模型的泛化能力。**围绕这两项问题安排三个实验，统一使用同一模型平台。

### 1.1 研究问题一：哪些相似性有助于判断预测质量？

**结构预测模型训练完成、参数固定后，目标复合物与训练样本的哪些相似性，在模型自身的置信度评分和输入质量之外，仍能提供关于预测误差的有效信息？**

首期核心指标包括单链序列相似性、同一参考复合物内的链对序列相似性、单链结构相似性和整体组装几何相似性。它们分别描述组成蛋白、配对关系、单链折叠及两链相对位置是否接近训练样本。进化谱、结构域组成与排列、表面理化特征和模型内部表示按数据可得性及额外成本分阶段加入；模型内部表示指模型根据输入计算出的数值特征。

首先检验结构几何能否在序列、模型置信度和输入质量之外提供有效信息，再考察较高成本的特征是否带来进一步收益。研究优先级同时考虑额外计算量、信息增量和实际预测时的可用性；不能只按工具运行速度排序，也不预设模型内部表示一定更有效。分阶段安排见第 1.5 节。

这一问题包括两个层次。首先，通过已有实验结构检验相似性与误差的关系是否稳定。随后，选取实际预测时能够计算的指标，评估其能否帮助识别高风险结果，并估计预测失败的概率。风险评估是这一研究问题的应用验证，与误差分析共享基础预测和候选特征，但需要另外检查概率是否准确、结果筛选是否有效。

**这里的“解释误差”指统计关联及额外的预测信息。相关性本身不能证明模型内部的因果机制；评估风险时，也不能使用新目标尚未知晓的真实结构。**

### 1.2 研究问题二：按相似性选择训练样本，能否改善预测？

**在模型架构、训练起始参数、样本数量和训练更新预算相同的条件下，依据候选相似性指标选择新增训练样本，能否提高模型对独立测试集中新复合物的预测质量？**

实验比较随机选择、依据链对序列相似性选择，以及联合序列与整体组装几何选择三种策略。各组从同一组权重开始，采用相同程序更新结构预测参数，再在同一独立测试集上比较结果。

这项研究检验的是样本选择带来的实际训练收益。某种相似性能够识别容易出错的目标，并不意味着按它补充数据就能减少错误；这一点必须通过训练对照验证。样本更分散或覆盖指标更高，也不能替代预测质量的实际改善。

### 1.3 两项研究问题与三个实验的对应关系

| 研究问题 | 实验模块 | 主要任务与结果 |
|-|-|-|
| 问题一：相似性能否帮助判断预测质量 | 实验一：相似性与预测误差分析 | 比较候选指标，识别已有信息之外与预测误差有关的相似性，并说明适用范围 |
| 问题一的应用验证 | 实验二：预测风险评估 | 将实际预测时可获得的相似性信息用于失败概率估计，检验概率准确性和高风险结果筛选效果 |
| 问题二：相似性能否指导有效的数据选择 | 实验三：训练样本选择 | 通过相同样本数与训练更新预算下的实际训练，比较不同选样策略对新复合物预测质量的影响 |

实验一、二固定结构预测模型的参数，另外拟合用于估计误差和失败概率的辅助模型。实验三固定结构预测模型的架构和共同训练起点，改变新增训练样本并更新参数。三个实验分别报告误差分析、风险评估和训练干预的结果；任何一项取得改善，都不预设其他实验也会成功。

### 1.4 研究范围与实施安排

首期任务是预测已知结合伙伴形成的异源二聚体结构：复合物由两种蛋白各一条链组成，比例为 1∶1，两链合计长度暂定不超过 512 个残基。训练样本从已有实验结构库中选择，效果在与训练和方法开发过程隔离的目标上评价。本期不研究相互作用是否存在、结合强度或更大多聚体的结构预测。

主要评价对象是新的蛋白家族组合。为统一比较各训练策略，将共同使用的训练数据和全部候选数据合为家族分层的统一参照集合；评价对象的家族组合不在该集合中。两条链所属的家族可能都已出现、仅一个出现，或都未出现，三种情况分别报告。“同一家族”按预先规定的序列分组规则判断，详细划分见第六节。模型在更早的训练中使用过哪些数据另行核查，历史数据不完整时，相关结论限定于能够核验的参考范围。

项目采用 **OpenFold3-preview2 的公开初始权重与官方 OpenFold3 0.4.5 软件**，训练和主要推理使用同一固定版本。第四、五节说明模型配置与实验评价标准，第六、七节说明数据及相似性指标，第八至十节依次展开三个实验，第十二、十三节给出进度与资源估算。

**本文的样本规模、预期改善幅度和成本情景均为计划值，尚未经过实验验证。主模型、初始权重和软件版本已在第四节明确；运行参数及资源配置依据首周数据检查和试运行确定，统计精度在方法开发阶段复核。**

### 1.5 按资源需求分阶段开展研究

**首期完成“序列、配对关系和结构几何”这条研究主线，大规模模型内部表示建库作为条件性扩展。**目标是在八周内完成误差分析、风险评估和实际训练对照，同时检验复杂特征是否值得投入更多资源。

| 实施层次 | 相似性与工作范围 | 实施条件 |
|-|-|-|
| 首期核心 | 单链序列；同一参考复合物内的链对序列；单链结构；整体组装几何 | 优先复用序列和已有结构坐标。至少保留一种反映两链相对位置的几何指标，检验序列和单链折叠是否已经足够。 |
| 有条件补充 | 已有多序列比对（MSA）支持的进化谱；可复用的结构域注释；简单表面组成；适用的公开预计算特征 | 资料来源清楚，增量成本可承担，不推迟核心实验。浅 MSA 仍可参与适用的匹配分析，但须记录信息量和不确定性。 |
| 可选扩展 | 大规模指定权重的内部表示提取；多个表示层与汇总方式；大规模细化界面或接触比较；为全库重新生成缺失的进化输入 | 先完成小规模可行性与增量收益试验，再决定是否扩展；单列建设、查询、更新和存储预算。 |

进化谱是由同源序列比对得到的位置偏好等统计描述。结构几何可直接从已有坐标计算，不等同于重新运行结构预测模型；相反，某些模型特征若已有适用缓存，追加成本也可能较低。实施层次根据实际数据条件确定。[29,30,42]

长度、链长比例、氨基酸组成和界面大小主要作为难度或质量控制变量。只有明确了与参考样本的比较规则，并检验其额外信息后，才将相应比较作为独立的相似性指标。

**可选扩展的进入条件：**在不使用最终测试结果的前提下，先用有代表性的开发样本和相同参考清单，比较“核心相似性＋模型置信度”与“相同信息＋新增特征”。只有增量收益在预定分层或重抽样中方向一致、不是少数异常样本造成，且全部新增成本可纳入排程，才扩大计算范围。通过开发检查不等于证明有效；科学结论仍须由独立评价支持。正式启用范围最迟在第 4 周、校准前固定。

若内部表示扩展启用，新目标可在正常预测过程中同步提取紧凑特征；历史参考可能仍需按指定权重重新计算。分别测量两侧成本。未开展某项扩展不影响核心方案的完整性，也不能据此声称该特征无效。

## 二、研究背景与研究价值

### 2.1 复合物结构预测的泛化特点

复合物结构预测需要同时处理各条链的内部折叠和链间组装。即使两条链各自都接近实验构象，它们的相对位置、朝向或接触关系仍可能出错，因此需要分别评价单链结构与链间组装质量。[1,2,13]

首期聚焦异源二聚体，能够在控制链数、界面数量和计算规模的同时，保留复合物组装这一核心问题。

### 2.2 目标与训练数据可以在哪些方面相似？

定义相似性，需要同时说明比较的对象、所用的特征，以及如何汇总目标与训练集的关系。比较对象可以是整条链、结构域、局部表面或整个复合物；序列、进化、几何、理化性质及模型表示，则是描述这些对象的不同方式。

| 比较角度 | 需要区分的问题 |
|-|-|
| 单条蛋白链 | 训练数据中是否分别存在与 A、B 序列相近或折叠相似的链 |
| 进化谱 | 目标序列是否符合训练参考链相关家族的氨基酸偏好等变化模式；两侧信息充分时，其进化谱是否相近 |
| 结构域组成与排列 | 两条链各自包含哪些结构域，其数量、排列及链间组合是否接近训练样本 |
| 两条链的家族组合 | A、B 所属家族是否曾在同一个训练复合物中共同出现 |
| 组装方式和相互作用界面 | 是否存在结合表面、残基接触关系及链间相对取向相似的训练样本 |
| 表面理化特征 | 目标与训练参考复合物的表面化学组成是否相近；有条件时以埋藏面积加权的氨基酸组成为近似描述 |
| 模型内部表示 | 参考样本与目标的链内或跨链数值特征是否相近 |

这些角度可以交叉使用。例如，界面既可以按几何形状比较，也可以按表面化学性质或模型表示比较。训练数据分别包含 A–C 和 B–D，并不代表其中已有 A–B 组合；即使两条链所属的家族相同，不同的结合位置或相对取向也可能形成不同的组装方式。各类相似性是否与误差有关、是否提供额外信息，需要逐项检验。

本文用“训练数据覆盖程度”概括相近样本的数量、与目标的距离，以及这些样本是否来自相互独立的家族或组合。它描述的是训练数据与目标的关系，不直接等同于模型能够正确预测该目标。多序列比对（multiple sequence alignment，MSA）汇集同源序列的进化信息；其信息量、参考进化谱是否可用和结构域注释是否完整另行记录，避免把信息不足直接解释为相似性低。

### 2.3 相似性、数据划分与泛化结论

样本相似是否构成数据泄漏，需要结合实际应用目标判断。预测已出现家族的新组合、包含一个新家族的复合物，以及两条链均来自新家族的复合物，具有不同的数据划分要求。随机划分是否合适，取决于预期任务和样本之间的依赖关系，并不存在适用于所有任务的统一相似性阈值。[5,12,19]

因此，本项目先规定评价场景，再据此划分数据。同时核查公开模型是否曾使用相关样本或近似样本，包括历史训练中的实验结构、蒸馏数据，以及训练和预测时的检索材料。蒸馏数据是以其他模型的预测结果作为标签的训练数据。结构公开日期和序列一致性阈值只能提供部分依据，还需结合数据来源和使用记录判断。

### 2.4 研究结果的应用方向

研究结果可用于两类决策：从已有复合物结构中选择增量训练样本，以及判断一次结构预测是否值得信任。前者需要实际训练收益的证据；后者除误差关联外，还需要检验概率准确性和结果筛选效果。

概率校准是检验并调整估计概率，使其与实际发生频率相符。例如，若一组预测被赋予约 20% 的失败概率，应检查其实际失败比例是否接近 20%。本期只研究已有实验结构的选择与预测结果的评价；如何安排新的结构测定实验，需要后续验证。

## 三、研究现状与预期贡献

相关研究已经涉及相似性约束的数据划分、训练样本选择、模型质量评分和概率校准。本项目的重点是在同一复合物预测体系中，检验具体相似性指标是否提供额外信息，以及据此选择样本是否带来真实训练收益。

基线方法是用于比较的对照方法。本项目先纳入模型置信度与输入质量，再依次加入序列、单链结构和整体组装几何。进化谱、结构域、表面与内部表示的额外价值在核心对照之上按条件检验，不将其全部列为八周内的必做任务。

| 方向与相关工作 | 已有进展 | 本项目需要补充的证据 |
|-|-|-|
| AlphaFold-Multimer（AFM，AlphaFold 多链模型）、AlphaFold 3、OpenFold 3 与 Protenix-Mini [1–3,17,22] | 复合物结构预测、链间信息建模和模型自身的置信度评分 | 训练数据相似性是否能在已有质量指标之外提供额外信息 |
| OpenFold 的训练数据干预 [4] | 通过改变结构类型和训练数据量研究泛化能力 | 在复合物预测中比较具体相似性指标，并通过受控训练检验选样收益 |
| SNAC-DB：抗体及单域抗体—抗原复合物数据库与评估研究 [40,41] | 结构新颖性分层、置信度排序分析，以及 GeoDock 的实际微调对照 | 多类相似性在已有质量信息之外的额外价值；固定候选池、样本数和更新预算下的选样效果 |
| DataSAIL（考虑相似性约束的数据划分方法）、PINDER（蛋白质相互作用数据与评估资源）[5,12] | 按相似性约束划分数据、整理复合物数据并检查泄漏 | 除规定如何划分数据外，检验哪种相似性能够反映当前模型的预测难度 |
| Trust Score（根据训练样本近邻关系计算的可信度评分）、深层表示最近邻方法 [6,7] | 利用目标与训练样本的距离或分布关系，评估可信度和识别分布外样本 | 检验这些指标能否反映实际对接误差，以及在新样本上的风险评估价值 |
| 核心子集选择、数据 Shapley 值（按平均边际贡献衡量样本价值）[8,9] | 根据样本间距离选择代表性子集，或衡量训练样本贡献 | 在使用结构标签的实际训练中验证样本选择策略 |
| HHsearch（谱与谱比对工具）与 HMMER（进化谱构建及检索工具）的比较 [24,25] | 利用序列与进化谱、进化谱与进化谱的匹配识别同源关系 | 检验与训练参考谱的匹配是否提供误差信息，并明确浅 MSA 条件下的可靠性 |
| 结构域组成与排列比较 [26] | 以结构域及其组合描述蛋白相似性 | 检验整链序列指标未充分反映的局部模块与组合信息 |
| MaSIF 表面描述 [27] | 将局部表面的几何和化学特征编码为可比较的描述 | 检验预测表面的理化相似性是否提供额外信息，并区分相似性与目标自身的界面质量 |
| 神经网络概率校准 [10] | 区分评分排序能力与概率准确性 | 对所有基线采用同等校准条件，比较风险估计的增量改进 |
| 复合物置信度校准的相关研究 [11] | 将 AlphaFold 评分转换为结构质量超过给定 DockQ（复合物对接质量评分）阈值的概率 | 检验相似性信息是否能在充分校准的基线之上改善风险评估 |

进化谱、结构域和表面描述的已有研究，证明了相应比较方法的可行性；它们是否能解释本项目模型的预测误差，仍需由独立实验验证。[24–27]

Sagadinov、Viliuga 与 Elofsson 于 **2026 年 10 月 12 日**发布的预印本《Calibrating AlphaFold confidence scores for interface quality》与本项目直接相关。该文研究了置信度评分到界面预测成功概率的校准，以及校准方法在不同数据分布之间的适用性，目前仍属于预印本。[11]

**SNAC-DB 是与本项目直接相关的研究。**其 2026 年正式论文面向抗体及 VHH 单域抗体—抗原复合物，区分新抗原、新表位（抗原中被抗体接触的区域）和新结合构象，并分析置信度排序的局限；研究还包含 GeoDock 在 SNAC-DB 与 SAbDab 两套训练资料上的实际微调比较。[40,41]

该训练对照的含义需要准确界定。作者公开的 2026 年手稿第 2.4 节记载，两组使用相同初始权重、超参数和结构簇加权规则，但 SNAC-DB 的训练集更大，两组实际训练轮数也不同。这为改进整理后的训练资料能够带来预测收益提供了证据；单凭该对照，还不能判断收益分别来自数据量、样本构成还是训练量，也不能单独确定聚类加权本身的效果。[40]

**本项目的预期贡献限定为两方面。**第一，在模型自身置信度、输入质量和序列信息之外，检验单链结构及复合物组装几何还能提供多少误差信息，并用预测时可取得的特征，在独立数据上验证失败概率的准确性与筛选效果。第二，在同一候选池、相同新增样本数量、相同初始权重及参数更新预算下，比较随机、序列覆盖和序列与几何联合覆盖三种选样策略的实际训练收益。前者由实验一、二共同回答，后者由实验三回答。

结构新颖性分组、近邻检索和训练资料多样性已有研究基础。本项目的价值取决于上述增量比较和受控训练能否产生可靠证据，不能仅以使用另一模型或另一数据集作为创新依据。误差关联不直接证明模型的学习机制，选样结论限于实际实施的候选池、策略与微调设置；历史训练资料不完整时，仍须区分已确认的训练样本与补充参考资料。

## 四、模型配置、运行检查与实验设置

两个研究问题在同一模型平台上开展，以保证相似性分析、风险评估和训练干预具有共同参照。模型与软件版本在本节明确；运行参数依据开发样本检查确定，所有正式实验设置均在查看最终测试结果前固定。

### 4.1 模型选择依据

**本项目采用 OpenFold3-preview2（OpenFold 3 第二预览版）的公开权重，训练与主要推理均基于官方 OpenFold3 0.4.5。**研究对象为蛋白质复合物，首期聚焦异源二聚体，保留多序列比对输入及相应处理流程。

选择这一组合，主要考虑历史训练资料能否核查、复合物训练样本能否控制，以及实际参数更新能否复现。OpenFold 3 公开了结构训练、微调和数据处理流程；链与界面缓存可用于追踪实际采样对象。Preview 2 另有对应的技术报告和蒸馏数据资料，有助于建立与指定权重相对应的参考库。[17,22]

权重版本与软件版本分别固定。Preview 2 描述本项目的初始模型参数及其训练历史，0.4.5 描述执行训练和预测的软件实现；采用 Preview 2 权重并不要求退回其最初发布时的软件版本。0.4.5 是本项目固定使用的官方兼容版本，具体发布记录见参考资料 [17]。

本期集中完成这一平台上的受控实验。Protenix、AlphaFold-Multimer、MSA Pairformer 等模型用于相关研究比较或后续扩展，不列入本期必须完成的多平台评测。选择依据不包含未经验证的精度或成本优势；实际资源需求在首周测量，研究结论首先适用于本项目的架构、权重起点、输入条件和数据范围。

| 检查项目 | 通过条件 |

| 复合物预测 | 在长度、链长比例和 MSA 信息量不同的开发样本上生成可评价的双链结构，并记录失败和重跑原因 |

训练成本测量固定输入规模、有效批量和参数更新范围。有效批量是每次参数更新汇总的样本量，包含梯度累积所涉及的样本。比较推理实现时，保持候选结构数量和其他科学设置一致，分别记录首次运行、已有缓存后的运行和失败重跑成本。

主模型不因出现新版本或少量开发样本的一次精度变化而更换。仅在以下实质障碍出现时，重新评估实施方案：核心训练数据无法核验，且限定参考范围后仍不能回答研究问题；必要的复合物训练流程经限定时间排查后仍无法运行；或合理优化和统一缩减非核心工作后，实测成本仍超出已落实资源及项目期限。历史资料局部缺失时，先限定参考范围与结论，不自动触发换模型。

必要变更须记录证据、原因及对训练参考库、共同训练起点、风险校准和实验可比性的影响，在正式数据选择实验和最终测试前确定。若仍无法完成训练干预，提交已验证的阶段结果并明确尚缺的实验及资源，不以另一平台的结果直接补入原有对照。

### 4.4 MSA、模板与输入条件

配对 MSA 按物种等规则将不同链的同源序列配成对应行，可能提供链间关系的信息。固定序列数据库快照、配对规则、配对和非配对 MSA 深度、随机种子及缺失信息处理方法，分别记录两条链和配对序列的信息量。用于相似性计算的参考进化谱另行保存来源、构建配置、有效信息量及覆盖范围，并与结构模型实际使用的 MSA 输入区分。

模板是预测时提供的已知结构。主方案使用官方 OpenFold3 0.4.5 支持的模板流程，按公开日期和结构身份过滤；模板库及规则与模型权重分别记录。排除目标自身和直接重复模板，报告其余同源模板的相似程度及覆盖范围。若试运行后决定关闭模板，应在正式登记前统一确定，全部实验采用相同设置。

MSA 和模板可能同时用于训练与预测。核查分别记录历史训练中的检索材料和本次预测的输入，并与结构监督、蒸馏样本清单区分。无法恢复的历史检索输入列为缺失信息。分析时控制当前检索质量，避免将其影响误归因于结构训练数据的相似性；结论限定于实际使用的输入条件。

### 4.5 预测配置与候选结构选择

随机种子控制样本选择、训练和预测中的随机过程。在已固定的 OpenFold3 0.4.5 与 Preview 2 初始权重基础上，首周进一步固定依赖软件、主干循环次数和扩散采样参数。主干循环指重复运行特征处理模块；扩散采样指通过多步去噪生成结构。

资源计划暂按每个目标使用 **1 个随机种子、生成 5 个候选结构**计算，再按预先确定的模型自身评分规则选出 1 个主要预测结果。针对一个复合物生成全部候选结构、计算置信度评分并排序，计为一次完整预测。循环次数和去噪步数根据所选权重的合理配置、实测质量及成本确定，并记录与公开基准的设置差异。[17,22]

主要预测结果的选择不使用由实验结构计算的 DockQ。按 DockQ 选择的最佳候选只用于事后分析性能上限，与模型自身规则选出的结果分别报告。若在正式登记前调整候选数量，同步更新工作量和预算。

**无有效结构时的处理：**首周固定结构有效性检查、最多重试次数与终止条件，所有模型采用同一规则。暂按每个目标最多重试 2 次规划，正式次数在预登记时固定。基础设施故障可在相同输入、随机种子和配置下重试；不通过更换种子或查看真实结构不断尝试。有效性检查限于文件可解析、目标链及必要坐标存在、数值有限等条件，不因 DockQ 较低、接触错误或碰撞较多而排除结果。记录每次尝试、失败原因与实际用量。

持续无输出或输出不可评价时，直接标记为预测失败，不伪造 DockQ 数值。全部预定目标保留在有效结果率的分母中；总体成功率以标签已核验的全部预定目标为分母，只有生成可评价结构且达到第 5.2 节质量阈值才计为成功。结构质量、误差与风险分析的共同可评价样本及覆盖率，按第 11.2 节分别报告。

### 4.6 加速推理实现与结果一致性检查

**训练与主要推理以官方 OpenFold3 0.4.5 为基线。**首先检查该版本支持的分块计算、显存优化和计算内核配置，固定实际启用的设置。第三方加速实现作为可选工程优化，不作为核心研究启动的前提；公开加速倍数不直接用于削减本项目预算。

**NVIDIA BioNeMo Inference Runtime（BioIR，结构预测加速运行库）**可在不影响主线进度时进行小规模验证，以 0.2.0 为核验起点并固定实际提交。其官方说明列出的 OpenFold3 权重为 `of3-p2-155k.pt`，并说明了自定义权重的加载条件。[45]这为复用本项目权重提供了实施入口，但与官方 0.4.5 的输入处理、数值结果及微调权重的兼容性仍需验证。

**Anthropic OpenFold3 optimization kit（OpenFold3 推理优化工具包）**作为适配候选。其 `openfold3` 方案固定 OpenFold3 0.4.1 与 Preview 2 权重，尚不能据此认定与本项目 0.4.5 兼容。Exact 模式的逐位一致性针对工具包规定的 0.4.1 基线及确定性条件；Fast 允许数值差异以进一步提速，Big 面向大输入的显存优化。这些结论不能直接转移到 0.4.5。只有完成适配并通过下述检查，才考虑启用；面向 OpenBind-0 的另一套工具包不用于本项目。[46]

在独立开发样本上，以官方 0.4.5 为对照，保持权重、多序列比对、模板、随机种子、循环次数、去噪步数、候选数量和评分选择规则一致。检查实际载入的参数，确认微调后的参数没有被默认公开权重替代；训练输出含多份参数副本时，固定用于评价的同一份。比较结构质量、置信度数值与排序、有效输出比例、耗时和显存，并预先规定可接受的差异。仅有置信度相关系数较高，或小样本中差异不显著，不能据此认定结果等价。公开初始权重的检查不能替代对共同起点及具有代表性的微调权重的检查。

所有正式对照统一使用通过检查的推理实现、版本和数值配置；若兼容性或输出差异不满足要求，统一采用已验证的官方 0.4.5 实现。风险模型的特征生成、拟合、校准和测试必须对应同一套输出条件；改变实现后，对受影响的特征重新生成并重新校准。减少循环次数、去噪步数或候选数量属于预测方案调整，按第 4.5 节单独记录。若启用内部表示分析，还需核对特征提取位置、维度与汇总定义，不能直接混用不同实现导出的表示。

推理加速、训练加速和 MSA 检索优化分别核算。结构模型的前向计算提速不代表输入准备或参数更新同比提速；完整预测、训练更新、MSA 检索及模板处理分别按第十三节记录实测成本。

## 五、实验假设、共同起点与评价标准

以下用 Q1、Q2 分别表示预测质量评估和训练样本选择两项核心问题。三个实验各自设置评价指标，结果按所属研究问题解释。

DockQ 是取值为 0–1 的复合物对接质量指标，综合接触关系恢复情况和结构偏差，数值越高表示质量越好。固定 DockQ v2 的具体版本及链对应规则：先依据序列身份确定异源链的匹配关系，对等价链置换使用一致规则。[13]

| 实验及所属问题 | 可检验假设 | 主要评价指标 |
|-|-|-|
| 实验一：相似性与预测误差分析（Q1） | 纳入模型置信度、输入质量、序列和单链结构相似性后，整体组装几何仍能提高新组合预测误差的估计准确性 | 对 $e=1-\mathrm{DockQ}$ 的平均绝对预测误差 |
| 实验二：预测风险评估（Q1 的应用验证） | 加入实际预测时可获得的相似性指标后，失败概率估计和高风险结果筛查优于经过同等校准的基线 | Brier 分数，即预测失败概率与实际 0/1 失败标签之差的平方均值 |
| 实验三：训练样本选择（Q2） | 训练起点、样本数量和训练更新预算相同的条件下，序列与几何联合选样优于仅按链对序列相似性选样 | 按预定规则确定的共同可评价目标上的平均 DockQ；同时报告全体目标的有效结果率和总体成功率 |

若序列与单链结构信息已经足够，整体组装几何未提供额外信息，这同样是研究问题一的明确结果。条件性特征的作用在核心对照上分别检验；未启用的特征不作有效或无效的判断。实验一、二分别评价误差估计与风险判断，共同说明相似性的作用及其应用范围。

### 5.1 共同训练起点与数据定义

用 $\theta_0$ 表示固定的公开模型权重，$D_0$ 表示各实验共用的增量训练集。先从 $\theta_0$ 训练得到共同基准模型 $\theta_A$。实验一、二固定 $\theta_A$ 的结构预测参数；误差和风险评估模型在 $D_F$ 上拟合、在 $D_V$ 上选择配置，风险模型再用 $D_C$ 进行概率校准。各数据集的用途和划分见第六节。实验三的所有结构训练从同一 $\theta_A$ 开始。

历史参考集 $D_H$ 包含与 $\theta_0$ 对应、能够核验的原训练材料，以及单独标记的补充参考资料；$D_0$ 是本项目新增、能够精确记录的训练数据。实验一、二分别计算目标相对于 $D_H$、$D_0$ 及二者合并后的相似性，以区分历史资料和本项目增量数据提供的信息。共同基准 $\theta_A$ 使三个实验建立在可控的模型起点上。对公开模型 $\theta_0$ 进行额外完整评价，须另列工作量和预算。

### 5.2 质量阈值与统计精度

主要失败标准暂定为 $\mathrm{DockQ}<0.23$，对应常用的最低可接受对接质量边界；0.49 可作为预先登记的次要质量阈值。[13]预登记是指在查看正式测试结果前写定分析方案。阈值衡量结构预测质量，不直接说明功能或结合强度；主要阈值、评价权重和输出选择规则均在最终测试前确定。

计划将以下幅度作为具有实际价值的改善目标：实验一的误差预测损失和实验二的 Brier 分数，相对主要基线降低约 5%；实验三在共同可评价目标上的平均 DockQ 绝对提高约 0.02。这些数值用于项目规划，其中 0.02 并非公认标准。首周初步检查可行性，第三周复核统计精度，在第四周正式登记前确定目标幅度。

最小可检测效应是在给定样本量和噪声水平下，有合理把握检出的变化幅度。实验一、二可根据开发集结果估计精度。实验三还需估计策略间配对差值的方差和重复训练的波动，不能用 $\theta_A$ 单个模型的 DockQ 方差代替。缺少有代表性的训练对照时，只能按假定方差范围估算检测能力，并注明这些假设；不能预先认定 200 个目标足以检出 0.02 的差异。

lDDT（局部距离差异评分）用于评价各条链自身的折叠质量，同时报告界面接触恢复情况和明显原子碰撞。[21]若策略只改善单链结构而未改善链间组装，应据此限定结论。

## 六、数据来源、训练记录与数据划分

三个实验共用一套数据来源、相似性计算方法和评价规则。数据划分既要保证结构预测模型没有在本项目训练中使用测试目标，也要避免误差与风险模型通过近似样本间接获得测试信息。

### 6.1 数据集及计划规模

实验结构来自 PDB。PINDER 可提供复合物候选、数据整理方法和数据泄漏检查思路；所选模型是否曾使用过这些样本，仍需结合具体权重单独核查。[12]

| 数据集 | 计划规模 | 用途 |
|-|-|-|
| 历史参考集 $D_H$ | 与所选权重对应、能够核实的序列、结构及训练阶段清单；注明尚未取得的部分 | 分析历史训练数据的覆盖程度；分别标记实际训练样本、补充参考样本、实验结构标签和教师模型预测标签 |
| 首批历史参考 $R_H$ | 300 个按预定分层抽取的复合物 | 用于特征提取试跑、成本测量和初步分析；正式参考范围按全量已知资料及实测资源确定，300 不是上限 |
| 共同增量训练集 $D_0$ | 500 个复合物 | 从 $\theta_0$ 训练得到 $\theta_A$，完整记录实际抽取的训练样本 |
| 新增候选集 $D_P$ | 1,000 个复合物 | 每种策略每次从中选择 200 个样本 |
| 应用样本集 U | 200 对已知结合伙伴的序列及固定 MSA | 按预先声明的应用范围独立抽取，描述需要预测的复合物类型；不使用其真实结构标签 |
| 误差与风险模型训练集 $D_F$ | 400 个复合物 | 拟合误差预测模型和风险预测模型 |
| 开发集 $D_V$ | 200 个复合物 | 从预先限定的方案中选择特征和训练配置 |
| 校准集 $D_C$ | 200 个复合物 | 风险模型确定后，仅用于概率校准 |
| 最终测试集 $D_T$ | 200 个复合物 | 全部实验方案确定后，用于统一评价 |

用于质量分析的 $D_F$、$D_V$、$D_C$、$D_T$ 共含 1,000 个目标，加上 200 个应用样本 U，核心方案需由 $\theta_A$ 完成约 1,200 次预测。共同训练集、候选集和首批历史参考优先使用已有标签结构建立几何参考。若开展预测来源对照或内部表示研究，再为所需参考追加模型计算，并单列预算。最终数量以质量检查和数据划分后的统计为准，不用重复条目补足计划样本量。

历史样本分别标记为“确认用于训练”“仅作为参考”和“是否用于训练未知”。科学目标以完整训练资料为参照；实施中分别报告各类特征实际取得、核实和成功处理的范围。$R_H$ 是首批试跑与缓存清单，其最近邻不能代表全量训练集最近邻；正式扩展方式、规模检查及成本计量见第 6.6、6.7 和十三章。

研究问题一分别评价 $D_H$ 和 $D_0$ 所提供的相似性信息，并报告两者合用的效果。历史资料缺失较多时，结论限定为“可核实参考数据中的相似性”。研究问题二的训练干预则针对完整记录的 $D_0$ 及后续实际加入的样本，能够准确说明各组训练了什么。

### 6.2 数据清洗与生物学组装体核查

主分析优先使用生物学意义明确的异源二聚体。每条链暂定至少含 50 个残基，两条链的输入长度合计不超过 512 个残基。首周核查数据后，确定分辨率、已解析残基比例、界面解析质量和最小有效接触等筛选标准。

以生物学组装体为单位核对链身份和各组分的数量关系，区分真实相互作用与晶体堆积形成的接触。排除重复提交的结构、相同组装或序列对的重复记录、链对应关系冲突、残基严重缺失，以及明显依赖输入中未保留组分的条目。

从较大组装体中提取链对时，需确认所研究的相互作用界面具有生物学意义，注明来源，并单独报告结果。训练时的裁剪方式与最终评价输入分别记录；任意截取的短片段不能代表原始完整复合物。

生物学组装与参与链完整性的核查，参考 SNAC-DB 对完整结合区域的处理思路。[40,41] 对每个候选条目保存原始组装编号、原始链到整理后链的对应关系，以及保留或排除该链的原因；若所研究的结合区域跨越多条链，不能把其中一条链的局部接触当作完整二聚体标签。抗体专用的区域识别和筛选规则只适用于后续抗体任务，首期一般异源二聚体使用本节规定的质量标准。

同源二聚体、抗体相关复合物、蛋白—短肽复合物，以及蛋白与核酸或小分子形成的复合物，属于后续扩展任务，首期不将其混入主要结果。非结合蛋白对通常没有相应的真实复合物结构，不能直接作为 DockQ 意义上的预测失败样本。

### 6.3 主要评价场景：新的蛋白家族组合

采用固定的 MMseqs2 序列检索与分组流程，以实际序列一致性不低于 30%、两侧覆盖均不低于 80% 的已识别关系建立相似关系图，并按连通分量分组。下文将这种操作性序列分组简称为“家族”；它不代表生物学分类的绝对边界。固定检索灵敏度、比对和分组配置；上述阈值用于定义本项目的评价场景，并非通用的数据泄漏判定标准，也不同于第 7.3 节的覆盖加权相似性分数。[29]

分组后，对用于本项目划分的研究样本再次进行跨组序列检索与比对复核。发现达到上述阈值的跨组序列对时，统一合并其所属分组，再重新生成数据划分；若因样本数量或质量约束需排除记录，按预先规定的规则执行，报告数量与原因。全部处理仅依据序列、身份和数据质量，不使用预测误差。检索仍可能遗漏远缘同源关系；不同分组不等于不存在任何生物学相似性。进化谱和结构域指标用于分析剩余相似关系，不依据测试结果反向修改分组。

每个二聚体用两个链家族的组合表示，不区分顺序，因此 A–B 与 B–A 归为同组。$D_0$ 与整个 $D_P$ 构成的集合，与评价数据按家族组合划分：同一家族组合和重复结构不得同时出现在两侧。某个链家族可以在 $D_0$ 或 $D_P$ 中以其他组合出现，这对应“已出现家族形成新组合”的场景。

以整个 $D_0\cup D_P$ 为统一参照，分别报告三类目标：两个链家族在参照集合中均有成员、仅一个家族有成员、两个家族均无成员。$D_P$ 中的候选样本并非全部用于每次训练；使用共同参照，是为了让各策略的分层标准一致。包含新家族的样本数不足时，仅作探索性分析。

### 6.4 评价数据之间的相关性与划分要求

$D_F$、$D_V$、$D_C$、$D_T$ 之间进一步限制链家族重叠：

1. 将家族视为节点，将复合物视为连接两个家族的边，按预定算法把家族分配到各数据集。
2. 只保留两端家族属于同一数据集的复合物，排除连接不同数据集的复合物。
3. 划分仅依据样本身份、长度、质量和数量要求，不使用模型预测误差。
4. 报告排除样本的比例及其对目标分布的影响，避免因共享结合伙伴过多而将全部样本归入同一个不可拆分的组。

用于主要分析的 $D_C$、$D_T$ 还需满足更严格的条件：每个家族在各自数据集中至多出现一次，选择过程不查看预测结果。其余存在家族重叠的样本用于扩展分析，计算区间时考虑样本之间的相关性。

如果无法为 $D_C$、$D_T$ 各获得 200 个符合条件的主要评价样本，先扩大原始候选范围；仍不足时，如实减少样本量并说明统计精度，不临时放宽划分标准。$D_F$ 内部可以保留共享家族，但交叉验证和调参需按家族关系分组。

U 与独立评价样本按共同预先声明的应用范围和分层规则抽取，不依据 $D_T$ 的具体组成定向选择 U。U 同样须满足第 6.3 节相对于共同训练集与全部候选集的新家族组合条件；这一规则在构建 U 时独立执行。本期将 U 作为独立应用样本集：排除与 $D_0$、$D_P$ 及所有评价数据完全相同的序列对和重复组装记录。允许 U 与其他集合共享单个链家族，但须报告实际重叠；这不放宽 $D_F$、$D_V$、$D_C$、$D_T$ 彼此的隔离要求。U 的真实结构不用于训练选样；若来自有结构记录的数据源，选样程序只接收其序列和规定的模型输入。

划分阶段可使用样本身份与序列完成去重和分组核查；训练选样阶段不访问 $D_T$ 的序列、模型表示、真实结构或预测误差，也不将最终测试目标加入 U。基准预测可由固定脚本提前生成，但最终测试标签与结果须封存，不进入开发分析。U 的来源、抽样规则和固定时间与数据清单一并保存。

### 6.5 历史数据使用情况与输入质量

按 Preview 2 权重对应的实验结构截止日期筛选数据，优先纳入此后公开的新增训练结构和评价结构，并检查相同或同源链对及相似界面。时间筛选只能减少部分已知重叠，不能替代训练来源、蒸馏资料和重复记录核查。

主要误差分析、概率校准和最终测试目标，排除能够确认已作为公开初始模型的结构监督或复合物蒸馏标签直接使用的目标复合物，以及同一输入序列对的等价重复组装。新的 PDB 编号或较晚的公开日期不自动代表新的预测目标。与历史样本同源但并非直接重复的目标仍可保留，记录其相似程度；组成蛋白曾出现在单体蒸馏数据中，也不等于整个复合物已经用于训练，须分别记录单链与复合物的历史使用情况。

日期或清单无法核实的样本，单独标记历史使用情况未知，并按可核验范围解释结果；未查到记录不能视为确认从未用于训练。较早公开的条目逐项核查，不以日期代替训练身份判断。若完成这些检查后的独立评价样本不足，如实报告数量和统计精度限制。

统一输入处理流程，并记录两条链的长度及长度比、配对和非配对 MSA 深度、有效序列数、缺口比例与比对覆盖率、是否缺少配对信息，以及实验结构质量。本项目用于输入质量分析的有效序列数按固定的去冗余权重规则计算，并保存具体算法。进化谱软件输出的有效序列数或多样性指标可能采用不同定义，另行记录，不混用数值或质量阈值。[25,28]

这些因素可能同时关联相似性与预测误差，需区分其用途。预测时可获得的链长、MSA 和模板质量可纳入实际风险评估的基线；实验结构分辨率、已解析残基比例和真实界面质量仅用于数据筛选、标签质量核查和回顾性分层，不作为新目标的风险特征，也不用于按 U 的真实结构选样。相似性的额外价值，应在控制相应可用信息后判断。

### 6.6 训练参考库的建设、查询与版本管理

训练参考库由样本主清单、各类参考特征和相应检索文件组成。它用于重复计算目标与训练资料的相似性。索引是为加快查找而预先整理的数据结构；建成索引并不代表检索没有遗漏，也不代表参考资料完整。不同特征使用同一主清单追溯来源，但可以具有不同的有效记录数。主要训练相似性只以确认参与相应模型训练的条目计算；补充资料和训练身份未知的条目另算参考相似性，不混入同一指标后仍称为训练相似性。若无法确认历史训练身份，则明确以 $D_0$ 的已知训练相似性和历史资料的参考相似性分别报告。

**科学目标以完整训练集为参照；实施时分别报告实际取得、确认参与训练和成功计算特征的范围。**每类特征都生成覆盖表，列出确认训练样本、补充参考、训练身份未知、处理成功、处理失败及实际入库的数量。完整训练清单的总数未知时，只报告已取得资料的规模及其可核验程度，不计算名为“完整训练集覆盖率”的百分比。首批 300 个历史参考样本用于流程检查、成本测量和初步分析，其数量不是正式参考库的固定上限，也不作为覆盖充分的证据。

| 步骤 | 具体工作 | 可核查的产物 |
|-|-|-|
| 1. 核实来源与样本单位 | 对应具体权重和训练阶段，区分原始结构、生物学组装体、链对、训练裁剪片段及标签来源；标记资料是否完整 | 参考主清单、缺失材料清单、模型与数据版本对应表 |
| 2. 规范化与去重 | 核对组成链和残基编号，执行适用于各类参考的序列与坐标质量核查；第 6.2 节的首期目标范围和输入长度限制不机械套用于全部历史参考。保存原始编号到内部编号的映射及排除原因 | 规范化序列和结构、链与残基映射、排除记录 |
| 3. 小批量测量并确定规模 | 按链长、来源和输入信息量抽取试跑样本，测量特征生成、查询及存储；估算全量已知参考所需资源 | 实测成本表、逐类特征的正式范围和资源计划 |
| 4. 固定计算规则 | 固定核心序列和几何指标的公式、软件版本、输入来源及缺失状态；条件性特征启用前另行固定规则。正式内部表示仅在启用相应扩展、$\theta_A$ 固定后生成 | 参数清单、模型权重校验值、软件版本或代码提交编号 |
| 5. 分批生成特征 | 先生成核心序列与几何特征，再处理已启用的补充特征；保存有效记录和失败原因，复用缓存并按需重算 | 核心产物为序列库、链对归属表、单链及复合物几何库；进化谱、结构域、表面和内部表示按已启用范围交付 |
| 6. 建立查询和结果汇总 | 采用第七章指定的检索方法，保存原始候选、链对应、分数和覆盖，再计算目标级指标 | 检索文件、原始命中表、最终相似性特征表 |
| 7. 检查质量与成本 | 分别检查搜索遗漏、参考规模影响和特征简化影响，测量单目标与批量查询 | 检索质量、参考覆盖和资源使用报告 |
| 8. 固定正式版本 | 在校准和最终评价前固定参考清单、特征与检索规则；任何更新均记录新版本及影响范围 | 可重建的正式参考库版本、查询配置与变更记录 |

各类库先按可比较对象定义范围：序列库可包含历史资料中的蛋白链，复合物几何与跨链表示则要求可追溯的链对或组装记录。因链数、组分类型、长度或训练裁剪信息不全而不能计算的条目，列入范围限制，不无声剔除。

去重按特征分别执行。完全相同的序列可以只保留一份计算结果，但保留其所属的全部复合物；相同序列与不同伙伴、不同组装构型或不同输入条件对应的结构和模型表示，不自动合并。若为节省空间采用聚类代表，保存被代表样本的编号和簇大小；簇大小不等于训练时的实际采样次数。最近邻统计不通过复制同一计算记录人为补足数量。

序列库优先扩大已核实训练序列的覆盖；单链与复合物几何库优先利用已有坐标，按适用对象、获取成本和实测处理能力确定正式范围。单体蒸馏结构可补充单链参照，但不能构成复合物配对或组装参照。进化谱、模型表示及预测表面描述不要求达到同等规模。比较特征本身的增量价值时，另在相同参考清单上计算对照，避免将参考库大小造成的收益误认为特征更有效。

核心参考几何直接来自已有标签坐标，查询几何来自 $\theta_A$ 的正常预测，两类来源分别记录。若启用内部表示扩展，其参考和查询必须使用相同权重、输入与提取配置；初始公开权重的接口试跑结果不能混入 $\theta_A$ 的正式表示空间。训练选样复用 $D_0$、$D_P$ 的标签结构及 U 的预测结构，不要求为全部参考重新预测。

新目标由序列与结构通道分别产生候选；内部表示通道仅在对应扩展启用时加入，需要联合复核时取候选并集。不得仅按序列阈值筛选，再把该范围内的结构近邻称为全库结构近邻。原始结果保留参考与特征版本、候选来源、链对应、分数、覆盖、返回数量及状态。新增参考不使用最终测试结果选择；校准集和测试集的真实结构不进入风险评估参考库。

借鉴 SNAC-DB 分别检索组成部分与完整复合物的做法，[41] 同一参考记录下关联完整复合物、组成链和已有局部界面文件，分别保存近邻结果；最近邻可以来自不同参考条目，不能把各层最高分拼成一个实际不存在的完整复合物。筛选日志同时记录阶段、参考编号、原始评分、链对应、覆盖及去留原因。若后续使用 SNAC-DB 的公开数据，须固定归档版本，并逐条核验其训练身份；数据库收录或早于某个日期，均不能单独证明该条目参与过指定权重的训练。

### 6.7 参考库质量检查与计算验收

**三类检查分别实施。**第一类是在同一参考集合上检查检索是否遗漏近邻；定长向量用准确的全量距离计算作基准，结构比对采用更充分的成对搜索作对照，但不将启发式结构比对称为数学上保证最优的真值。第二类检查参考规模：先在已生成的历史参考中构造 100、200、300 个样本的嵌套子集，并重复抽样；若仍随规模显著变化，按实测预算扩大参考范围。仅在该范围稳定，不能证明全量训练资料已被充分代表。第三类检查特征简化：比较汇总、压缩或高速近似是否改变分数、近邻排序及开发集上的误差和风险评估结果。

序列和几何库的规模检查优先使用已有特征；高成本表示库仅在小规模扩展启动后开展相应检查，不为绘制规模变化曲线预先生成大库。各检索通道按自身的适用对象和实测成本分批扩展，不要求所有通道同时覆盖全部历史数据。

若正式启用近似向量检索，预设工程目标为前 5 个近邻的召回率不低于 0.99，即平均找回准确搜索前 5 个结果中的至少 99%；这是本项目的检索质量目标，不是生物学通用阈值。并列距离按相同规则处理，另报最近邻距离偏差及不同类别的遗漏情况。近似方法返回候选后，用保存的未经量化的紧凑向量，按照同一套固定的标准化、归一化与距离规则重新计算分数；低相似性、长链和低置信度目标单独检查。未达到要求时采用准确搜索或扩大候选，不以速度替代质量要求。

工具速度在同一批输入、同一参考范围和同一评分要求下比较，分别测量首次运行与已加载数据时的耗时、单目标与批量查询、处理器占用、峰值内存、显存、磁盘和失败重跑。单次查询报告中位数与第 95 百分位数，后者表示约 95% 的查询不超过该耗时。计时包括特征提取、数据搬运、检索、候选复核和结果汇总，不仅统计搜索内核。最终选择在检索质量要求下总成本更低的实现，并报告它相对于一次正常结构预测增加的成本。

## 七、相似性计算定义、工具与信息使用范围

### 7.1 统一定义：样本之间的评分与相对于训练集的汇总

每项相似性均明确比较对象、输入来源、成对评分、链对应、参考范围、查询方法及不可用状态。以下公式属于本项目的预设操作定义，是否提供有效的误差信息需要实验验证，不将工具性能等同于科学有效性。

用 x 表示目标复合物，r 表示参考复合物，T 表示明确列出的训练参照集合。对于数值越大越相似的成对评分 s，理想的最大相似性为 

$\displaystyle S(x,T)=\max_{r\in T}s(x,r)$；

对于距离 d，则用最小距离 

$\displaystyle D(x,T)=\min_{r\in T}d(x,r)$。

若搜索仅返回候选集合 $C(x)$，报告的实际值在 $C(x)$ 上计算，并注明搜索方法与限制。只有在全部有效参考上准确计算，才能称为给定特征下的准确最近邻。

主汇总采用最近邻分数或距离，以及前 5 个有效参考的平均分数或距离；复合物近邻另记录其中不同家族组合的数量。5 是项目预设参数，10 和 20 仅用于开发阶段登记的敏感性检查，不在最终测试中择优。参考不足时记录实际数量；无有效结果、信息不足和计算失败分别标记。填补值只供辅助误差或风险模型的数值输入使用，不用于制造命中、构造近邻或认定相似性为零。

单链结果与链对结果分别保存。对于两条链组成的目标 (A,B) 和同一个参考复合物 (C,D)，链对相似性统一采用：

$\displaystyle s_{\mathrm{pair}}=\max\left\{\min\left[s(A,C),s(B,D)\right],\min\left[s(A,D),s(B,C)\right]\right\}$。

该公式比较两种链对应关系，并要求每种对应中较弱的一条链也有支持。两条链分别命中不同参考复合物，只能说明各链有相似参考。分数不能比较或一侧不可用时，不产生有效链对分数。结构工具给出的残基比对和完整组装评分采用第 7.6 节的专门规则。

| 特征类别 | 计算对象与分数 | 实施层次与用途 |
|-|-|-|
| 单链与链对序列 | 序列一致性乘以两侧覆盖度的几何平均；链对须匹配同一参考复合物 | 核心；序列基线和训练选样 |
| 单链结构 | 各链独立结构比对，取目标、参考两侧归一化结构分数的较小值 | 核心；区分单链折叠与复合物组装信息 |
| 整体组装几何 | 两条链在共同空间中的整体结构评分；两侧长度归一化后取较小值 | 核心；主要增量比较和序列与几何联合选样 |
| 参考进化谱 | 目标序列对参考谱的局部匹配分数，按目标与谱长度校正 | 条件性补充；优先复用已有同源比对 |

### 7.3 单链与链对序列相似性的计算

采用 MMseqs2 进行参考链检索，并取得实际比对的一致性和回溯信息。序列一致性 

$\displaystyle I=\frac{\text{相同残基的比对列数}}{\text{比对列总数}}$，

分母包含内部缺口列；$c_q$、$c_r$ 分别为目标与参考实际参与比对的非缺口残基数占各自有效序列长度的比例。明确启用实际一致性的计算方式，并从保存的比对回溯重算一致性与两侧覆盖，不把工具的默认估计量直接当作相同定义。[29]

主分数定义为 

$\displaystyle s_{\mathrm{seq}}(q,r)=I(q,r)\sqrt{c_qc_r}$。

这是覆盖加权序列匹配分数，取值 0 到 1；短局部匹配即使一致性很高，也不会自动等同于整条链相似。原始一致性和两侧覆盖同时保存，纯一致性在预定覆盖条件下的结果仅作补充对照。链对分数按第 7.1 节计算，序列距离定义为 $1-s_{\mathrm{pair}}$。

记录原始比对分数、比对位置、缺口、目标与参考长度、链及复合物编号。同一对链有多个返回比对时，按固定原始比对分数及并列规则选取一个，再计算本项目分数；不声称已遍历所有可能比对以最大化覆盖加权分数。首周配置以每个查询最多保留 10,000 个预筛选候选为起点，实际小库取全部可用条目，并检查候选数增加对链对命中和最大分数的影响；这不是“所有比对均已计算”的保证。加速预筛选、筛选阈值和最终输出截断均进入版本配置。没有返回匹配时标记为“当前检索条件下无有效命中”，不写成准确零相似性。

单链指标分别在整个参考链库中寻找 A、B 的最佳结果；链对指标在同一个参考复合物内匹配。对实验三中规模受控的 U 与 $D_0\cup D_P$，显式生成全部查询链—参考链组合，使用 MMseqs2 align 按冻结的局部比对规则逐对计算，不经过候选检索。固定替换矩阵、缺口罚分和组成偏好校正等参数，并取消会截断所需配对的输出限制。将预期配对清单与实际结果逐项核对；未报告或失败的配对须查明原因并补算，不能填为零相似性。只有固定比对规则明确得到空比对时，才按预设规则记为零。完整矩阵通过核对后再用于选样。

### 7.4 条件性补充：参考进化谱与浅多序列比对

本节仅在参考同源比对可复用、建谱及检索增量成本可承担时实施，不要求首期为全部历史参考重新生成 MSA。启用后统一采用目标序列搜索参考进化谱。参考谱使用隐马尔可夫模型，即描述序列位置偏好及插入、缺失规律的概率模型；目标自身即使只有一条序列，也可与已有参考谱比较。[25]

参考链优先复用同版本、来源明确的同源比对缓存；缺少缓存的记录先标记为资料不足，仅在预先确定的小规模补充范围内，用固定数据库和检索参数收集同源序列。保留原始比对、来源、日期及筛选规则，再用 HMMER 的 hmmbuild 构谱、hmmpress 准备谱库。查询采用 PyHMMER 的 hmmscan 语义，即目标序列搜索参考谱库，预载优化谱以减少重复读取，并用标准 HMMER 结果抽样核对。[25,32]

每个序列—谱匹配保存全序列分数、各局部匹配分数及位置。比特分数是相对于背景模型的对数评分，不是结构预测正确的概率。在已报告的序列—谱命中中，取已报告局部匹配的最高校正后比特分数，即 PyHMMER 的 Domain.score，作为 b，定义 

$\displaystyle s_{\mathrm{evo}}(q,r)=\frac{b}{\max(L_q,L_P)}$，

其中 $L_q$ 为目标链长，$L_P$ 为参考谱的匹配状态数。该长度校正是项目定义的匹配强度，不能假设已消除全部长度或谱质量影响；另保留目标和谱的覆盖、长度、质量及命中状态作为伴随信息。多个局部匹配不累加，以免重复结构域造成未明确控制的加分。链对使用第 7.1 节的同复合物规则。

显著性数值只用于标记匹配证据和筛选状态。主查询以 HMMER 默认报告规则为起点，完整记录数据库规模、滤波及报告参数；若修改查询方向或候选筛选，须核对评分和显著性定义。保存整条命中及局部匹配各自的 reported、included 标志，分别表示达到报告阈值和纳入阈值，它们不是结构预测正确性的判断。主相似性使用报告结果，较强匹配证据单独标记。随库规模改变的显著性统计量不直接混合。无报告结果、参考谱信息不足和计算失败分别记录；原始结果不填零，辅助模型的数值填补规则只在 $D_F$ 上拟合。[32]

参考谱记录原始序列数、项目统一的去冗余有效序列数量、软件内部的信息量指标、比对覆盖及缺口。外部同源序列是构谱材料，不自动视为结构模型实际使用过的训练样本。参考谱清单在最终评价前固定，不按测试目标或测试误差重新构建和筛选。不同参考范围上的序列基线同步计算。

谱对谱仅作为信息充分子集中的补充：采用 HHsearch，从原始比对生成其专用谱格式。补充分数为 

$\displaystyle s_{\mathrm{HH}}=\frac{\mathrm{Score}}{\max(L_Q,L_R)}$，

其中 Score 为原始比对分数，$L_Q$、$L_R$ 为两谱的匹配状态数；该长度校正仍属于项目定义。关闭二级结构评分，仅比较由多序列比对形成的进化谱。链对汇总采用第 7.1 节公式，并固定查询方向，不预设分数对称。另保存工具的匹配概率、覆盖和有效信息量，概率仅作为同源匹配证据，不解释为结构预测成功概率。质量要求结合多样性、覆盖、缺口和分数稳定性，在开发阶段确定，不设置跨工具通用的有效序列数阈值。[24,39]

使用通用先验或伪计数得到的谱，不等于获得了目标家族新的进化观测。[28]开发阶段对预先选定的参考比对减少同源序列，检验主方案的分数和近邻稳定性；目标侧抽稀仅用于谱对谱补充。此检查保持 $\theta_A$ 的预测输入和已有结构结果不变。主方案不使用目标自身的多序列比对，其匹配分数不应因目标侧抽稀改变；真实浅比对目标另行评价。

### 7.5 条件性补充：结构域组成与排列

优先复用来源、序列、版本、启用成员库和代表位置选择规则一致的结构域注释。若缓存来自全部成员库分析，可复用其中的原始 Pfam 命中，但须在固定的 Pfam 范围内重新选择代表位置，不能直接沿用跨成员库比较得到的代表位置标记；需验证重选结果与本项目规定流程一致。[33] 确需重新注释时，先测量处理成本，再决定启用范围。以下计算仅适用于已启用的补充分析，不作为核心实验的数据纳入条件。

采用固定版本的 InterProScan 6，仅运行 Pfam 分析并以便于保存结构化记录的 JSON 文本格式保存原始输出。结构域标签取 signature.accession 中的 Pfam 登录号；主方案保留 signature.type 为 Domain、位置 representative 为 true 的命中，即成员库标为结构域且被选作代表位置的记录。一条位置记录计为一次结构域出现，同一位置记录中的不连续片段不重复计数。相同标签与完全相同位置的重复记录合并，其余重复结构域保留。按起点、终点、标签排序，得到结构域标签序列。保存版本、位置、分数、代表位置标记及完整注释；不要求每个 Pfam 标签都有关联的 InterPro 整合条目。结构域注释不等于已确定真实结合界面。[26,33]

组成相似性保留重复次数。设 $n_q(a)$、$n_r(a)$ 为标签 a 在两条链中的次数，则 

$\displaystyle s_{\mathrm{comp}}=\frac{\sum_a\min\left[n_q(a),n_r(a)\right]}{\sum_a\max\left[n_q(a),n_r(a)\right]}$。

排列相似性为 

$\displaystyle s_{\mathrm{order}}=1-\frac{\operatorname{Edit}(A_q,A_r)}{\max\left(\text{长度}(A_q),\text{长度}(A_r)\right)}$；

Edit 表示将一个标签序列改成另一个所需的最少插入、删除、替换次数，三种操作代价均为 1。两项均在 0 到 1 之间，首期使用等权标签，不根据最终结果调整常见域权重。

两项分别按第 7.1 节汇总为链对指标，再计算对参考库的最大分数。比较的两条链 q、r 按上述规则均没有可用结构域标签时，记为不可比较，不赋值为 1；仅一侧有标签时数学上得分为 0，但同时标记单侧无可用标签，解释为当前注释下无共有模块，不能直接断言生物学上不存在结构域。注释失败与成功运行但无命中分别记录。

### 7.6 单链结构、整体组装与局部几何

实际风险分析使用 $\theta_A$ 按第四节规则选出的预测结构作为目标输入。核心几何库直接使用已有训练标签坐标，区分实验结构和教师预测结构，不为入库重复运行预测模型。通用结构库不自动视为真实训练库。使用目标实验结构的版本只作回顾性分析；在相同参考子集上比较“预测目标—预测参考”属于可选来源对照，其额外预测需计费。

**单链结构相似性。**用 Foldseek 分别检索两条链，固定采用可输出结构比对与双侧归一化评分的模式。TM-score 是衡量三维结构相似程度的评分，越高表示越接近。单链主分数取按目标和参考长度归一化的 TM-score 较小值，同时保存残基对应和两侧覆盖。[30]

$$\displaystyle s_{\mathrm{chain}}(q,r)=\min\left(\mathrm{TM}_{q},\mathrm{TM}_{r}\right)$$

两条目标链分别保存最近邻和前 5 个近邻的平均分数。其最佳参考可以来自不同复合物，只能说明各链折叠有相似参考；若另作链对结构汇总，须采用第 7.1 节的同复合物规则。单链评分允许各链独立叠合；整体组装评分则必须保留两链共同的空间关系，不能把两个独立叠合结果相加后称为组装相似性。

整体组装作为首期必做的复合物几何指标，优先用 Foldseek-Multimer 搜索。保存分别按目标和参考总长度归一化的评分，主分数为 

$\displaystyle s_{\mathrm{assembly}}=\min\left(\mathrm{TM}_{\mathrm{target}},\mathrm{TM}_{\mathrm{reference}}\right)$。

对应工具字段为 complexqtmscore 与 complexttmscore；同时保存两侧覆盖、链对应及对应方案编号。二聚体主分析要求两条链均有有效对应，同一对结构有多个返回方案时取主分数最大者，并记录选择过程。返回方案中的最好结果不等于穷举所有可能比对的保证。[30]

若启用局部界面扩展，采用 Foldseek-Interface。界面条目按两链主链 α 碳原子邻近关系提取，以距离不超过 10 Å、每侧至少 4 个有效界面残基作为核验起点；Å 为埃，1 Å 等于 $10^{-10}$ 米。核对固定代码提交的实际参数和边界条件，记录调整。重新生成界面结构编码并检索，主分数采用两侧界面长度归一化评分的较小值，另保留覆盖及原复合物编号。[31]

整体评分和界面评分是两个指标，不能相互替代。针对候选和预定的小型审计集合，使用固定版本 US-align 进行成对结构比对，检查链对应和评分差异；其自身也采用启发式方法，不将其命名为绝对精确比对。[38]

接触模式仅作预先登记的细化对照。先由结构比对建立链和残基对应，再定义跨链接触：两个残基之间任意非氢原子距离不超过 5 Å。把目标与参考的接触映射到共同的有效残基对集合，计算交集大小除以并集大小。仅在共同有效残基对集合为空，或映射后的接触并集为空时记为不可用；并集非空但交集为空时，评分为 0。另报参与比较的残基覆盖和被排除的接触比例；如另设覆盖门槛，须在试跑后冻结。该评分只描述已建立对应部分的接触重合，不能直接比较不同长度、未对齐的原始接触矩阵。这里的非氢原子接触与界面检索采用的 α 碳邻近定义分别记录，不混作同一指标。

没有预测界面、没有有效结构命中和结构处理失败分别记录。DockQ 在本项目用于预测结构与其相应真实结构之间的质量评价，不作为任意两个不同复合物的通用相似性。

SNAC-DB 按不同结构层次组织新颖性分析，为分别解释组成部分和整体结合方式提供了参考。[40,41] 本项目据此强调比较单位的一致性：从较大组装体中提取的双链，其整体评分仅描述这两条链的构象，不能代表原多链复合物的整体新颖性。所有几何评分均记录实际参与比较的链和归一化范围。SNAC-DB 的基准筛选与近邻展示采用的评分口径不能直接替代本节定义，其阈值也不能视为跨任务通用的泄漏界限。目标实验结构得到的相似性只用于回顾性分层；实际风险模型使用预测时可取得的特征。

### 7.7 可选扩展：模型内部表示的提取与比较

本节在第 1.5 节的进入条件满足后实施，不作为核心建库或训练选样的前提。若启用，预设只取 $\theta_A$ 最后一次主干更新后的残基对表示。Pairformer 是处理残基及残基对关系的模块。张量接口、导出时点和通道数 c 在兼容代码中核验并登记；有效位置排除填充及无对应残基，并固定输入链排序和推理配置。

将每个有效跨链位置的 $A\times B$ 表示 $z_{ij}$ 与 $B\times A$ 表示 $z_{ji}$ 分别作为一条记录，组成多重集 V；多重集保留数值相同的重复记录，每个有效位置及方向贡献一次。对每个通道计算 

$\displaystyle \mu=\frac{\sum_{v\in V}v}{\lvert V\rvert},\qquad\sigma=\sqrt{\frac{\sum_{v\in V}(v-\mu)^2}{\lvert V\rvert}}$，

再拼接为 

$\displaystyle \phi_{\mathrm{global}}=[\mu,\sigma]$。

该向量有 $2c$ 个分量，与链长无关；不先平均每对双向表示再计算方差。对给定张量交换链标签，汇总结果不变，但重新交换输入后运行模型不保证逐位相同，因此仍需少量输入顺序检查。

逐分量的标准化均值和标准差只用固定 $D_0$ 参考清单拟合；以后历史参考库扩容时继续使用同一变换。标准差小于 $10^{-8}$ 的分量不参与距离计算，变换后再除以向量长度。这里 $10^{-8}$ 仅为数值稳定设置。主距离为 

$\displaystyle d_{\mathrm{repr}}(x,r)=1-\widehat{\phi}(x)\cdot\widehat{\phi}(r)$，

即余弦距离，$\widehat{\phi}$ 表示标准化并归一化后的向量；无有效长度或数值异常记为不可用。首期不额外进行低维投影。

上述汇总尽量在预测设备上直接完成，只长期保存紧凑向量、数值检查信息和必要的复核样本；不把全部残基对张量作为默认归档对象。固定累加精度，比较导出相对于正常预测增加的时间与显存。若只提取主干即可取得完全一致的主表示，可在验证输出一致性后省去参考侧不必要的后续生成步骤；其成本单独实测。

预测接触局部表示使用第 7.6 节的非氢原子 5 Å 接触规则，在所选预测结构的接触位置上计算相同的双向均值和标准差，并建立单独的补充查询；其标准化参数仅用 $D_0$ 中有效的局部向量另行拟合。无接触时该局部向量不可用，不用零向量生成近邻。全部跨链主表示仍保留，避免只在预测出的错误界面内计算特征。

链内对照取同一次主干末次更新后的单残基表示，具体接口与通道数另行登记。对每条链的有效残基分别计算逐通道均值和标准差；其标准化参数使用 $D_0$ 中全部有效链向量单独拟合，再按上述规则计算余弦距离。单链近邻分别报告；链对距离只匹配同一个参考复合物，定义为 

$\displaystyle \min\left\{\max\left[d(A,C),d(B,D)\right],\max\left[d(A,D),d(B,C)\right]\right\}$，

即对两种对应取较大链距离的较小值。

扩展中的向量查询优先用 Faiss 准确距离计算，并比较中央处理器与显卡的完整耗时。只有准确扫描成为实测瓶颈时，才按第 6.7 节条件测试 cuVS 的近似索引，并用未经量化的向量复算。[34,35] 主要汇总为最近邻距离、前 5 个近邻的平均距离及家族组合数。内部表示先用于误差和风险的增量比较；按表示选样的训练对照须另列实验与预算，不属于首期三种策略。

均值和标准差不保留完整残基排列或接触拓扑，表示近邻不能直接等同于完整界面相似。内部表示比较固定使用 $\theta_A$，不能混合不同权重下的向量；若主干参数或相关输入协议改变，应重新生成受影响的参考特征。

启用前先核查可下载的预计算特征。已有工作确实公开过结构模型内部表示，例如 AlphaDTA 提供经结合口袋筛选的 AlphaFold 3 单位置与位置对特征；但其任务为蛋白质—小分子复合物，不能直接当作本项目 OpenFold 3 蛋白质—蛋白质复合物的表示库。[42] 复用时逐项核对样本、模型权重、输入协议、截取范围、数值处理和使用条件。不同来源的特征可建立各自固定编码器的对照，不混入同一个距离空间。

### 7.8 条件性补充：表面理化组成

本节仅在已有适用预测坐标或追加成本可承担时实施。目标和参考均使用 $\theta_A$ 按相同规则选出的预测构象；缺少参考预测时，不能将重新预测的成本视为零。主描述为按界面埋藏面积加权的氨基酸组成，作为粗粒度表面理化描述，不直接计算连续空间电势、实际氢键或完整表面形状。

主用 zsasa，采用 Shrake–Rupley 算法，即通过原子扩张球面上的采样点估计可接触面积，使用双精度、统一非氢原子集合、ProtOr 蛋白质原子半径规则和 1.4 Å 溶剂探针。首期采用每原子 1,000 个采样点，在试跑样本上与更密采样及同参数 FreeSASA 比较；所有半径、采样和异常原子处理写入配置。高吞吐的位掩码近似模式只在逐残基面积、埋藏面积及近邻排序检查通过后启用，不直接沿用其他数据集的误差数字。[36,37]

在同一预测构象下，分别计算孤立链和完整双链复合物的逐残基溶剂可及面积 $a_i^{\mathrm{single}}$、$a_i^{\mathrm{complex}}$；孤立链只移除另一链，不重新预测或松弛。定义 

$\displaystyle b_i=\max\left(0,a_i^{\mathrm{single}}-a_i^{\mathrm{complex}}\right)$。

对每条链 a，令 $E_a$ 为能够按预先固定的规则归入 20 种标准氨基酸、且原子处理通过质量检查的残基集合。对第 k 类氨基酸，定义 

$\displaystyle p_a(k)=\frac{\sum_{\substack{i\in E_a\\\text{类型为 }k}}b_i}{\sum_{i\in E_a}b_i}$。

非标准残基的映射或排除规则写入配置，同时记录被排除残基占总埋藏面积的比例。两链描述组成 

$\displaystyle v_{\mathrm{surface}}=\left[\frac{p_A+p_B}{2},\frac{\lvert p_A-p_B\rvert}{2}\right]$，

对交换链标签不敏感；主距离为两向量的欧氏距离，即各分量差平方和的平方根。

总埋藏面积和非标准、缺失原子比例另作质量记录。若所选预测构象中不存在非氢原子距离不超过 5 Å 的跨链接触，或任一链的有效埋藏面积不足以形成稳定组成，则该局部描述记为不可用；稳定性阈值在试跑阶段根据采样误差确定并冻结，不能按预测误差选择。无预测界面、数值不稳定和计算失败分别标记。

疏水、带电或供受体残基类别可用于解释组成差异，分类表须固定；带电残基占比不等于静电势，供受体组成不等于实际形成的氢键。本期不训练额外表面深度模型。[27]检验高速面积计算时，同时比较逐残基 $b_i$ 和最终描述，因为两次总面积的小误差可能在相减后形成较大的界面面积误差。

### 7.9 真实结构、缺失值与正式方案的确定

**实际预测时使用的风险特征，只能来自当时可获得的信息。**目标真实结构不用于风险特征、参考样本选择、距离变换、查询参数或校准前的方案选择。训练数据已有真实结构可用于结构监督、界面裁剪、质量控制和预先规定的训练样本选择；目标真实界面仅用于登记后的回顾性分析。

每项指标保留“有效值”“当前检索无有效命中”“资料不足”“不适用”“计算失败”等状态。辅助模型所需数值填补仅在 $D_F$ 上拟合，缺失标记同时进入对照；原始结果和查询记录不受填补影响。参考库、处理软件、模型权重或评分规则改变后，生成新版本，并重新检查相似性结果与风险校准。

以上主定义在实施前登记。首周允许为接口兼容和数值正确性调整实现，但必须说明原因；开发阶段仅检查已列出的少量敏感性方案。最终测试前固定全部公式、参数与参考范围，最终报告区分完整已知参考分析、参考子集验证、启发式搜索和准确计算，不将其混为同一证据。

## 八、实验一：相似性与预测误差分析

本实验回答研究问题一的基础部分：先描述相似性与预测误差的原始关系，再检验相似性在已有质量指标之外能否提供额外信息。结构预测模型 $\theta_A$ 的参数保持固定，只训练用于估计其误差的辅助模型。原始关联、其他指标之外的增量以及因果作用分别解释，不相互替代。

### 8.1 分析对象与原始关联

每个目标复合物对应一条分析记录，包含第七节定义的相似性指标、输入质量、模型自身置信度及与实验结构比较得到的 DockQ。用 $e_i=1-\mathrm{DockQ}_i$ 表示第 i 个目标的结构误差指标，数值越大表示质量越差。一个目标与多个参考的匹配结果，先按固定规则汇总；这些匹配不构成额外的独立预测样本。

对每类已启用的相似性，先绘制以相似性为横轴、结构误差为纵轴的散点图和分组趋势图，展示各组误差分布、样本数及不确定性；报告 Spearman 秩相关系数与区间。秩相关概括单调关系，不要求关系为直线；系数接近零不能排除分段或非单调关系。[44] 未命中或计算失败按缺失状态处理，不填为数值零后参加相关计算。单项描述仅使用该指标可计算的目标并报告覆盖率；比较不同指标的关联强弱时，另在共同可计算目标上核对。

分组数、分组边界的确定规则及平滑方式在开发阶段固定；最终测试图按同一规则生成，不按测试结果选择最显著的分组。按长度、MSA 信息量和家族出现情况分层，观察趋势是否只出现在特定类别。原始相关强弱不作为取消主比较或筛选测试特征的依据；非线性关系通过预先登记的敏感性分析复核。

### 8.2 基线方法与候选特征

pLDDT 是模型对局部结构质量的评分，ipTM 是模型对链间相对结构质量的评分；PAE（预测对齐误差）表示以某一位置对齐后，另一位置的预计偏差。对照方法采用所选版本实际提供的链对 ipTM、跨链 PAE、各链置信度评分和预测接触统计，充分利用已有质量信息。首周核实各字段、链对应关系和缺失值处理方式；仅使用全链平均 pLDDT 不足以构成这里的对照。[1,17]

| 方案 | 输入信息 |
|-|-|
| B0 | 模型输出的链对和各链置信度评分、预定预测接触统计，以及链长、长度比和 MSA 质量；启用模板时纳入模板使用状态、匹配质量和覆盖汇总，关闭模板时统一记录状态。使用预先限定的少量指标 |
| Bseq | B0 加单链和链对序列相似性，分别计算相对于历史参考集和本项目训练数据的数值 |
| B1 | Bseq 加单链结构相似性，分别描述两条链的折叠是否接近训练参考；保留覆盖、来源与缺失状态 |
| B2 | B1 加整体组装几何相似性，检验完整复合物几何在序列及单链折叠信息之外的价值 |

主要比较 B2 与 B1，检验整体组装几何的额外信息。进化谱、结构域、表面、细化接触和内部表示仅在对应扩展启用后，分别加入同一个 B2 作补充对照。每个补充方案、每个参考范围新增的相似性数值不超过 3 个，调参预算相同；不同时拼接全部高维特征。参考范围不同时，另报告相同参考清单上的对照。

补充分析区分两类比较。在 B0 中单独加入某类相似性，检查它在输入质量和模型置信度之外是否有价值；保留其他相似性，再加入或移除该类指标，检查它是否仍提供额外信息。后一种比较没有改善，可能意味着信息重叠，不能据此否定原始关联。仅对已启用特征开展预先指定的少量逐类加入和移除对照，各方案重新拟合，调参预算相同；不改变 B2 对 B1 的主要比较。增量的含义取决于已纳入的信息、评价目标和辅助模型。[43]

B1 中两条链的最佳结构参考可以来自不同复合物；因此，B2 的增量可能同时反映两种折叠在同一复合物中共同出现，以及它们的相对空间关系。本比较不将收益单独归因于链间取向或接触模式。若进一步区分二者，可按第 7.1 节规则补充“同一参考复合物内的链对单链结构汇总”对照，核对候选召回和两链评分后复用已有比对结果；该对照属于预先指定的辅助分析。

### 8.3 拟合与独立测试中的增量检验

各方案使用相同类型、参数数量受限的回归模型，采用相同的正则化方法和调参预算。正则化用于约束模型复杂度、减少过拟合。主方案预测结构误差 $1-\mathrm{DockQ}$，以平均绝对误差评价预测效果。非线性方法仅用于预先登记的敏感性分析，不直接用数万维表示拟合 400 个目标。

各方案在 $D_F$ 上拟合，在 $D_V$ 上确定辅助模型配置；核心几何定义与输入来源采用第 7.6 节的预定规则。正式结果在封存的 $D_T$ 上统一评价，主要比较 B2 相对于 B1 的误差预测损失变化，报告效果大小及区间，并按长度、配对 MSA 信息量和家族出现情况分层。辅助比较包括 Bseq 对 B0、B1 对 Bseq、B2 对 Bseq，以区分序列、单链折叠与复合物几何的信息。检验增量时，对照保留相同的质量、可用性和缺失标记，仅比较是否加入相似性数值。条件性特征的增减对照单列，不以其中最有利的结果替换主要比较。

主要增量定义为 B1 的平均绝对误差减去 B2 的平均绝对误差。设 $\widehat e_i^{B1}$、$\widehat e_i^{B2}$ 为两种辅助模型对同一目标结构误差的估计，n 为共同可评价目标数，则等权主要分析计算：

$$\displaystyle \Delta\mathrm{MAE}=\frac{1}{n}\sum_{i=1}^{n}\left(\left|e_i-\widehat e_i^{B1}\right|-\left|e_i-\widehat e_i^{B2}\right|\right)$$

正值表示加入整体组装几何后，误差估计更准确；负值表示估计更差。采用第 11.2 节的共同目标、配对重抽样与评价权重，报告绝对改善及其区间。另报告相对改善 $\Delta\mathrm{MAE}/\mathrm{MAE}_{B1}$ 及其区间，以对应第五节约 5% 的规划目标；每次重抽样同时重算分子与分母。基线 MAE 为零时不计算相对改善。相关样本组的扩展分析先按第 11.2 节汇总，再使用预定组权重。

**这里的 MAE 衡量辅助模型估计结构误差的准确程度。**MAE 降低时，固定的 $\theta_A$ 及其输出结构没有改变，也不意味着结构本身的 DockQ 提高；结构预测质量能否改善，由实验三检验。辅助模型比较始终使用同一批目标，不能因某方案缺少特征而另换评价集合。

### 8.4 结果解释与分析产物

相似性与误差存在原始关联，但纳入 ipTM 等置信度指标后没有额外收益，并不矛盾。它可能表示相似性提供的信息已被现有指标覆盖，也可能受到样本量、特征定义或辅助模型拟合能力限制。纳入模型置信度是为了检验实际使用中的新增价值，不能解释为消除了全部混杂或识别了因果作用。单次回归或相关分析未发现改善，不足以证明两者不存在任何形式的统计关系。

基于预测结构的几何相似性，是结构预测完成后才能取得的质量线索；预测错误本身也可能改变该相似性，因此不能直接把关联解释为训练覆盖不足导致预测错误。若只有基于真实结构计算的几何相似性有效，则结论限定为回顾性分析。几何指标也可能反映一般结构合理性；缺少规模与组成匹配、且能确认未用于模型训练的参考对照时，不能将其收益单独归因于模型记住了训练构象。增量效应与负结果的判据见第 11.4 节。

| 分析产物 | 必须报告的内容 |
|-|-|
| 原始关系图与汇总表 | 相似性与误差的趋势、秩相关及区间、分组样本数和可计算覆盖率；注明开发或最终测试来源 |
| 独立测试的增量结果 | 主要 B2 对 B1 的绝对与相对 MAE 改善及区间；预定次要对照分别列示，不择优替换主结果 |
| 分层与信息重叠分析 | 长度、MSA 条件及家族类别中的结果，以及已登记的逐类加入和移除对照 |
| 适用范围与使用成本 | 预测前或预测后可用、正式参考范围、缺失情况、计算成本及结论能够支持的用途 |

上述分析复用已有结构预测和相似性特征。辅助模型拟合与重抽样的处理器用量计入分析成本，核心结构预测与训练次数仍按第十三节规划；条件性高成本特征不因本章增加分析要求而自动启用。

## 九、实验二：预测风险评估

本实验是研究问题一的应用验证。它复用 $\theta_A$ 的预测结果，并采用实验一中实际预测时可获得的特征，检查这些信息能否用于真实结构未知的新目标，准确估计失败风险，并帮助筛选预测结果。结构预测模型的参数仍保持固定。

### 9.1 风险模型与独立校准

风险模型针对按模型自身评分规则选出的、可评价的最终结构，估计其 DockQ 低于预定阈值的概率。评价对象与实际交付结构一致；无有效输出的目标直接报告预测失败，不套用仅针对已输出结构校准的失败概率。

B0、Bseq、B1、B2 沿用实验一的输入信息，分别拟合正则化逻辑回归模型预测失败概率，并采用相同的正则化方法和调参预算。各风险模型在 $D_F$ 上拟合、$D_V$ 上确定配置，再用 $D_C$ 进行概率校准。校准时使用相同、参数较少的方法，例如逻辑校准；等渗回归，即保持分数次序的单调校准方法，可作为预先指定的对照。非线性风险模型仅用于预先登记的敏感性分析。各方案获得同等的校准条件，避免将充分校准的方法与未经校准的 ipTM 直接比较。[10,11]

正式参考清单、特征与查询规则及风险模型配置，在使用 $D_C$ 校准前固定。若开发阶段扩展参考库，用最终版本重算 $D_F$、$D_V$ 的相似性，并重新拟合；之后以同一流程计算 $D_C$、$D_T$ 的特征。主要比较 B2 对 B1；条件性特征仅按预登记的启用范围补充，采用同等拟合、校准和评价条件。目标真实结构只用于评价标签与回顾分析，不进入任何实际风险特征。

### 9.2 概率准确性与使用价值

主要报告以下结果：

- Brier 分数，以及按预测概率分组后的实际失败率和区间；
- 风险排序能力，以及按风险从低到高保留固定比例的预测后，剩余结果的失败率和平均 DockQ；
- 两个链家族均有参考样本、仅一个有参考样本、两个均无参考样本，以及配对 MSA 信息稀少等类别的结果；
- 目标 MSA 较浅、几何查询无有效命中等类别的结果与样本数；参考谱、表面等专项缺失分析仅在相应扩展启用时报告；
- 在实际参考库中未获得有效匹配，或处于预先规定的低相似范围的目标数量、缺失原因及主要错误类型。

风险排序、概率准确性和筛选后的预测质量反映不同用途，需要分别评价。[20] 概率的准确性通过独立样本中的实际失败频率检验，并不保证某个样本一定成功。本期校准对应第六节规定的、按家族筛选的异源二聚体评价总体，并以固定预测流程已产生可评价结构为条件。实际业务中各家族的比例、输入质量或失败率可能不同；应用前需用目标场景中有代表性的数据重新核验或校准，不能直接把本期概率解释为任意业务流量中的失败率。

实验一和实验二分别评价误差估计与失败风险，作为研究问题一的两方面证据报告。实验二的完整校准仅针对 $\theta_A$；实验三得到的新模型可能具有不同的误差分布，不能直接沿用 $\theta_A$ 的校准关系。九个新模型的核心预算只包含最终测试集上的结构评价，逐一建立并校准风险模型需另计预算。

## 十、实验三：训练样本选择

本实验回答研究问题二：依据相似性选择训练样本，能否带来实际的预测改善。各策略从同一 $\theta_A$ 开始，使用相同数量的新增样本和相同训练更新预算，实际更新结构预测参数。

### 10.1 三种样本选择策略

每次从同一个 $D_P$ 中选择 200 个复合物，尽量使各组在总长度、链长比例、实验质量和输入 MSA 信息量上的分布一致。

| 策略 | 选择规则 |
|-|-|
| $S_{\mathrm{random}}$ | 在预先规定的各层内随机抽样 |
| $S_{\mathrm{seq}}$ | 使用第 7.3 节的链对序列距离 $1-s_{\mathrm{pair}}$，降低 U 中样本到 $D_0\cup\text{已选集合}$的平均最近邻距离 |
| $S_{\mathrm{mix}}$（序列与几何联合） | 将链对序列不相似度与整体组装几何不相似度等权组合，使用与 $S_{\mathrm{seq}}$ 相同的覆盖目标和贪心选择规则 |

联合策略的操作定义为：

$$\displaystyle d_{\mathrm{mix}}(u,r)=\frac{1}{2}\left[1-s_{\mathrm{pair}}(u,r)\right]+\frac{1}{2}\left[1-s_{\mathrm{assembly}}^{\mathrm{pairwise}}(u,r)\right]$$

两项不相似度均在 0–1 范围，权重预先固定为各 1/2，不依据开发或测试表现择优调整。它是用于样本选择的综合不相似度，不假设满足数学距离的三角不等式。每一项均比较同一个目标与同一个参考复合物，并保存其链对应方案。序列与几何分项分别按各自规则确定链对应，可能采用不同对应；联合分数用于综合两类信息选样，不解释为同一链对应下的联合匹配。

应用样本 U 使用固定 $\theta_A$ 的预测结构；$D_0$ 和 $D_P$ 使用已有训练标签结构。候选标签本来可用于训练，因此可用于选样；U 的真实结构仍保持不可用。两侧构象来源的差异是该实用策略的一部分，须明确报告；两侧都用模型预测的来源对照属于额外研究。

此处成对整体几何使用固定版本 US-align 的复合物比对，要求两条链都有有效对应，并取目标、参考总长度归一化 TM-score 的较小值。[38] 该数学汇总与第 7.6 节相同，但比对算法和残基对应可能不同，不能假设与 Foldseek-Multimer 数值相等；首周抽样核对两种实现的评分、链对应和近邻排名。训练选择全过程固定同一成对实现。

两种基于相似性的策略都旨在增加训练集中与预期应用样本相近的案例。对于已选集合 S，优化目标为 

$\displaystyle F(S)=\frac{1}{\lvert U\rvert}\sum_{u\in U}\min_{r\in D_0\cup S}d(u,r)$。

每一步从满足分层配额的剩余候选中，选择使 F 降低最多的样本，直到选满 200 个；质量要求、分层配额和并列处理规则相同。U 不提供真实结构，也不包含最终测试目标。两种相似性策略使用核对完整的比较矩阵：按计划规模，200 个应用复合物与 1,500 个参照及候选形成 300,000 个复合物对。未去重时，序列部分对应 400 条查询链与 3,000 条参考链的 1,200,000 次链比对，几何部分对应 300,000 次复合物比对。这是有限矩阵的逐对计算，不是对全部历史库进行精细穷举。分别计量两类比较，链对应检查、重试及处理器占用均计入实测预算。

$S_{\mathrm{mix}}$ 固定采用上述等权组合，无论开发阶段是否显示其优于序列，均按预定流程完成训练对照。查询预测固定使用 $\theta_A$，参考坐标来源与比对设置保持不变；历史库扩展不改变本实验的覆盖目标或参照 $D_0\cup S$。不能把未返回或计算失败的结构配对填为最大距离，或据此把样本当作最值得补充的数据。

先对 U、$D_0$、$D_P$ 进行序列与双链结构完整性检查，对失败配对重试。按预登记、与预测误差无关的规则固定有效 U，再排除仍含无效配对的覆盖参照或候选，形成完整可计算的矩阵；三种策略使用同一候选范围与质量配额。$D_0$ 的排除只影响 F 的覆盖参照，不改变 $\theta_A$ 实际训练记录。若共同候选不足 200、有效查询或参照为空，或排除比例超过预登记的容许范围，应回到实现核验，或在正式登记前统一调整范围。报告全部排除数量、原因与组成，不将有效子集结论推广到未覆盖对象。

覆盖目标中的 U、参照集合和候选集合均指完成上述检查后的共同有效集合，并按实际有效查询数归一化。

首期仅比较上述三种训练策略。进化谱、结构域、表面及内部表示在满足数据和成本条件时补充误差或风险分析；关于训练收益的结论仅覆盖实际完成的选样对照。其他特征如有额外价值，可据此另行设计并预算训练实验。

本实验评价的是选样规则在相同样本数与训练更新预算下的效果。SNAC-DB 的数据库微调对照提供了训练资料影响预测结果的证据，但未单独比较固定候选池中的随机选样与相似性选样。[40] 三组采用一致的训练抽样与加权规则；如保留原训练程序中的簇或界面权重，应在共同候选范围内预先确定基础权重，按同一规则应用于各组。训练日志保存实际样本及界面的抽取次数，并与共同训练数据的回放比例、裁剪配置和实际计算量一并核查。主要结果使用第 10.3 节规定的固定更新次数终点权重。即使某种选样策略有效，也只能支持它在该设置下的实用价值，不能据此断定模型依赖相应相似性形成预测。

### 10.2 将选择结果落实到训练样本与界面

本项目按官方 OpenFold3 0.4.5 的数据缓存和采样流程执行训练。链或界面索引及预处理后的链编号须与原始记录对应，因此需要把选定的生物学组装体和双链界面映射到实际训练索引，记录结构编号、生物组装编号、原始及内部链编号、界面类型和标签来源。仅按 PDB 编号筛选，无法保证训练时只使用选定界面。[17]

检查实际采样日志，确认没有意外加入同一结构中的其他界面。训练裁剪后须同时保留两条目标链及有效界面；界面标签来自符合数据划分要求的训练结构，最终评价使用预定的完整双链输入。单链随机裁剪的训练结果，不能作为已干预复合物组装学习的证据。

### 10.3 统一训练程序

在官方 OpenFold3 0.4.5 中采用与 Preview 2 权重兼容的结构监督配置，确认主干和结构生成模块的相关参数获得有效梯度，并关闭“仅训练置信度预测模块”的模式。主方案是在有限更新次数内微调整个模型；若首周实测表明资源不足，可在正式登记前统一改为仅更新部分主干层和结构生成模块，并相应限定结论。

各策略采用相同的有效批量、裁剪与输入规模限制、MSA 上限、循环设置、扩散训练配置、优化器、学习率、损失权重、有效更新次数和权重保存规则。计划先进行 1,500 次共同训练更新，再为每次策略训练进行 2,000 次更新；具体设置根据开发稳定性和首周资源测量在正式登记前固定。这里的“相同训练更新预算”不等于实际显卡占用完全相同：各组另报实际卡时、处理器用量、选样开销与重跑成本。若用量差异超过预登记的容许范围，应说明算力未完全匹配，不能为追求相同耗时而临时改变某组的更新终点。

若使用 $D_0$ 回放，即继续混入共同训练集中的样本以减轻遗忘，各策略使用相同的清单、比例和采样规则。主要比较采用预定更新次数结束时的权重，不根据最终测试结果挑选中途权重。

一次有效更新的耗时包含梯度累积及全部参与设备的占用。本实验要求实际更新结构预测参数；改变 MSA、单独训练误差回归模型或仅训练置信度预测模块，均不属于这里定义的训练干预。

### 10.4 重复实验与结果比较

每种策略按预定流程运行 3 次，共 9 次策略训练，另有 1 次获得共同起点 $\theta_A$ 的训练。随机策略每次重新抽取 200 个目标；同一轮重复中的训练随机种子按预先确定的配对方案设置。

确定性的选择策略可能三次选中同一集合，应据实记录，并分别保存选样和训练所用的随机设置。3 次重复只能提供有限的波动估计，结论中应说明尚未充分考察的样本选择和训练随机性。

九个模型均在 $D_T$ 上评价，按固定流程生成候选结构，以模型自身评分规则选择输出，再计算 DockQ；按第 11.2 节统一处理无有效输出，分别报告共同可评价目标的质量及全体目标的有效结果率、总体成功率。报告全部重复，主要比较 $S_{\mathrm{mix}}$ 与 $S_{\mathrm{seq}}$，并报告相对于随机策略和未继续训练的 $\theta_A$ 的绝对变化。

若各策略均低于 $\theta_A$，应报告性能下降及策略间差异。若 DockQ 的提升主要来自单链折叠质量改善，而缺少链间组装改善的独立证据，应限定结论，不将其解释为已学到新的界面模式。

## 十一、统计分析、复现与结果解释

### 11.1 预先登记方案与最终测试

正式实验前登记数据清单、主要评价指标、失败阈值、评价权重、候选特征范围、选样规则、训练程序、输出选择、重试与终止规则、共同可评价范围、有效结果率的分母、随机种子、排除原因和统计脚本。实验一还需固定原始关系图的分组与平滑规则、主要增量的正方向、具有实用价值的改善幅度及其绝对或相对尺度，以及少量逐类加入和移除对照。特征记录包括各类正式参考范围、训练身份与有效记录数、公式与固定变换、软件及数据版本、查询参数、近邻汇总与检索验收条件，以及参考扩展的决定依据；同时保存有效序列数定义、质量标准和缺失处理。主要科学定义在实施前登记；开发阶段完成实现核验后，于第 4 周固定正式配置，调整须保留原因和记录。

第 4 周只报告开发阶段结果。三个实验的方案全部确定后，统一查看最终测试结果。若据此修改方案，原测试集转为开发数据，后续结论需另用独立测试集验证。

### 11.2 统计单位与区间估计

以复合物或具有相关性的样本组为统计单位，不将残基、原子、跨链接触或同一目标的多个扩散候选视为独立样本。主要校准集和测试集中的链家族不重复，各复合物采用相同评价权重；若同组保留多条记录，先计算组内平均值，再赋予各组相同权重。三个实验使用同一套预定的目标权重。

**先固定评价规则，再报告可评价范围。**实验一、二在同一组具有 $\theta_A$ 有效预测和可评价真实标签的目标上比较；单项相似性缺失按第七节的缺失规则处理，不因某方案缺少特征而另换目标集合。实验三的主要平均 DockQ 比较使用 $\theta_A$ 与全部九个训练模型均有可评价结构的共同目标集，并报告其占预定测试集的比例。这个均值描述“各模型均能给出可评价结构”的条件性质量；各模型另在全体目标上报告有效结果率和总体成功率，不能仅凭条件性均值升高宣称整体交付表现改善。

无有效输出不赋予虚构的 DockQ，也不进入需要结构误差标签的回归或概率校准。若运行后发现真实标签本身不可评价，按预定、与方法表现无关的规则对所有方法统一处理，单列数量与原因，不记作模型预测错误。所有排除及其对目标组成的影响均须报告。

主要比较采用配对自助抽样，即以目标或相关样本组为单位有放回地重复抽样，估计结果区间。训练策略比较先对每个目标计算三轮配对训练的平均差，再以目标为单位重抽样；所得区间以这批已训练模型为条件。另报每次训练的结果及三次重复之间的波动，不将目标抽样区间解释为已涵盖全部训练随机性。存在共享家族的扩展数据，使用考虑样本相关性的稳健统计方法，并报告有效组数。

实验一对第 8.3 节的配对损失差进行重抽样，始终保留同一目标上两种辅助模型的结果；秩相关和分组趋势的区间采用与目标相关结构相符的抽样单位。主要结果报告 95% 区间，具体区间算法、重复次数和随机种子在开发阶段固定。固定辅助模型后的测试重抽样，主要反映测试目标抽样的不确定性；辅助模型拟合与选参的稳定性，另由开发阶段按家族分组的交叉验证或重复拟合检查，不能把测试区间当作已涵盖全部开发选择的不确定性。

首周初步估计可用目标数和预测失败样本数；第三周根据固定 $\theta_A$ 的开发结果，复核误差分析和风险评估的方差与失败样本数，并在正式登记前确定分析方案。训练样本选择实验的检测能力，还需考虑策略间配对差值的方差和重复训练波动。缺少有代表性的对照结果时，仅在假定方差范围内做敏感性分析，不自动增加预算外训练。

小规模试跑用于判断工程可行性，不足以可靠估计效应大小。样本过少时，应报告较宽区间，或将结论限定为探索性结果。

首期指定一个主要组装几何方案，以及一项训练策略的主要比较，即 $S_{\mathrm{mix}}$ 对 $S_{\mathrm{seq}}$。其他几何、进化谱、结构域、表面、模型内部表示、阈值与生物类别分析列为次要或探索性分析，按预登记的方法处理多重比较。内部表示等扩展通过开发阶段筛选后，仍须独立评价；未作相应统计处理的结果不作为确认性显著结论。

### 11.4 两项研究问题的结论范围

研究问题一由误差分析和风险评估共同回答。实验一检验相似性是否提供已有指标之外的信息；实验二检验这些信息在给定目标分布和输出规则下，能否用于实际风险判断。两者共享数据与特征，分别报告误差估计、概率准确性和筛选效果，作为同一研究问题的不同证据。

研究问题二由实际训练干预回答。其结论适用于给定模型起点、候选数据和训练更新预算，不能仅由样本分布更分散或相似性与误差相关来推断。单个模型上的结果也不足以说明所有架构都依赖同一种相似性。

相似性未提供额外预测信息、风险估计未得到改善、样本选择未改善结构预测，或校准方法无法迁移，均属于有效结果。对于实验一，增量效应的区间整体位于零以上，支持在规定数据范围和分析设置下存在正向增量；若区间仍包含预定的实用改善边界，则实际价值的大小仍不确定。区间跨过零时，不能确认稳定的正向收益，也不等于证明相似性与误差无关。若区间足够窄，其上限已低于预先规定的实用改善幅度，可以说明当前结果不支持达到该幅度的收益；区间较宽时须保留尚无法排除的可能性。效应与判定边界使用同一绝对或相对尺度，次要比较按预登记的多重比较规则解释。各项结论均限定于实际数据、特征定义、参考范围和辅助模型条件。

历史资料优先取得样本清单、元数据与序列，已有结构按适用范围分批下载建库。序列和几何索引为核心；大规模内部表示及全库新建参考进化输入不列为启动前提。模型预测本身所需的 MSA 与模板准备仍须计费，不能因参考进化谱分析可选而省略。下载、预处理、索引、查询、存储与失败重算分别记录。

### 13.2 工作量与计算成本公式

实验一、二共用 $\theta_A$ 对 1,000 个质量分析目标的预测，训练选样另需 U 的 200 次预测；实验三九个继续训练模型各评估 200 个测试目标，共 1,800 次。**核心合计约 3,000 次完整预测，每次包含 5 个候选结构的生成、置信度计算与排序。**已有标签结构直接用于参考几何。对 $D_0$ 的 500 个、$D_P$ 的 1,000 个及首批历史参考的 300 个样本重新预测，共 1,800 次，属于可选来源对照或特征扩展；只有实际需要时才运行。仅提取内部表示时还应比较主干提取方案，不能机械按完整预测计费。

共同起始模型的训练暂定为 1,500 次参数更新，实验三的九次策略训练各进行 2,000 次更新，共计 19,500 次有效参数更新。更新耗时包括梯度累积、前向计算、反向传播，以及实际启用的结构预测和置信度计算分支，并合计所有参与设备的占用时间。卡秒是各设备占用秒数之和，例如两张卡运行 60 秒相当于 120 卡秒；卡时按相同方式合计设备占用小时数。

总卡时 

$$\displaystyle \begin{aligned}G&=1.25\Biggl[G_{\mathrm{pilot}}+\frac{3{,}000\,t_{\mathrm{pred}}}{3{,}600}\\&\qquad+\frac{19{,}500\,t_{\mathrm{update}}}{3{,}600}+G_{\mathrm{build,extra}}+G_{\mathrm{query,extra}}\Biggr]\end{aligned}$$

其中：

- $G_{\mathrm{pilot}}$ 暂取 80 卡时，用于环境检查、训练稳定性检查和工程试运行；
- $t_{\mathrm{pred}}$ 为一个复合物完成整次预测所需的卡秒数，包含 5 个候选、评分与排序；仅在启用对应扩展时，追加表示汇总和导出的实测增量；
- $t_{\mathrm{update}}$ 为一次完整优化器参数更新所需的卡秒数；
- $G_{\mathrm{build,extra}}$ 为未计入基础预测和试运行的 GPU 输入准备、参考特征生成及索引建立和重建卡时；包括实际使用 GPU 完成的 MSA 检索或其他模型输入预处理，已在其他项目计费的作业不重复计入；
- $G_{\mathrm{query,extra}}$ 为未计入其他项目的 GPU 查询、候选复算和检索质量检查卡时；
- 1.25 为重跑和调度预留 25% 余量；
- CPU、数据库存储、下载和服务费用另行核算。

核心几何参考使用已有坐标，不新增模型前向计算。历史表示和预测来源对照按互斥任务计费：完整预测数乘以实测完整预测耗时，或仅提取主干表示的数量乘以实测提取耗时；后者须先通过第 7.7 节的一致性检查。已有缓存直接复用。随核心预测提取表示时，只追加尚未包含的增量。每个作业只归入一项费用，避免重复计入预测、建库和查询。

核心序列与几何处理、训练选样成对计算及模型输入准备，分别记录处理器核时、峰值内存、磁盘和失败重算；核时是各占用核心运行小时数的总和。选样矩阵在未去重、未重试时对应 1,200,000 次链序列比对和 300,000 次复合物几何比对，实际数量按去重和重试日志确定。进化谱、结构域和表面按实际启用范围计费，优先复用序列、MSA 或已有预测。首次建库、单目标查询、批量查询及更新成本分别报告。结构比较虽无需重跑预测模型，其处理器和工程成本也不能忽略。

各类参考规模用 $N_m$ 分别记录。内部表示扩展若启用，仅长期保存紧凑向量：采用 32 位浮点数时，N 个、每个 $2c$ 维的向量约需 $N\times 2c\times 4$ 字节，另加编号、质量记录及索引。该式不含权重、结构、MSA、临时内存或复核张量；不能从向量文件很小推断生成成本很低，也不预设初期存储足够容纳全量历史资料。

平均耗时按计划中的序列长度和 MSA 分布加权计算，并单独报告长输入所需的额外资源。训练稳定运行后的耗时与首次编译耗时分开记录；编译和启动计入工程试运行，避免在每次更新中重复计费。

### 13.3 不同耗时条件下的资源需求

下表采用三组假定耗时，估算核心预测与训练的基础资源，并分析运行速度对预算和进度的影响；额外 GPU 输入准备、建库与查询尚未计入，CPU 输入准备及其他费用另行核算。**这些耗时均为规划假设，不是 OpenFold3 0.4.5 或第三方加速实现的实测性能。正式预算先以官方 0.4.5 的完整流程测量为依据，再按通过验证的实际实现更新；表中数值不代表资源需求的上限或下限。**

| 情景 | 每个目标 $t_{\mathrm{pred}}$ | 每次更新 $t_{\mathrm{update}}$ | 预测卡时 | 训练卡时 | 含 80 卡时试运行与 25% 余量的基础卡时 |
|-|-|-|-|-|-|
| A | 180 卡秒 | 120 卡秒 | 150 | 650 | 约 1,100 卡时 |
| B | 600 卡秒 | 300 卡秒 | 500 | 1,625 | 约 2,756 卡时 |
| C | 1,200 卡秒 | 600 卡秒 | 1,000 | 3,250 | 约 5,413 卡时 |

可先按约 1,100、2,800、5,400 卡时三档准备核心实验询价，再增加实际发生的 $1.25\left(G_{\mathrm{build,extra}}+G_{\mathrm{query,extra}}\right)$。若确需追加全部 1,800 次参考预测，三档含余量的增量分别约为 113、375、750 卡时；届时完整预测总数为 4,800 次。大量历史表示扩展仍须另算，不能认为这些增量已经包含全库计算。价格和预约条件以实际供应情况为准。

例如，假定八周内设备可用率为 70%，2／4／8 张同型号设备分别可提供约 1,882／3,763／7,526 卡时。可用率仅用于估算排程。除总卡时外，还需考虑各项实验的先后依赖，核对第 4 周以后重复训练的可用时段、并行运行能力和评估时间。

B 情景下，九次策略训练本身约需 1,500 卡时；四张设备按 70% 可用率计算约需 22.3 天，训练后 1,800 次评价另需约 4.5 天。若按训练后集中评价的顺序估算，并为这段工作同样预留 25% 余量，合计约需 33.5 天；实际排程还须结合任务能否交错运行及可预约时段核查。因此须在第 4 周按已固定方案尽早启动训练，并安排第 7–8 周的评价与报告，不能预设第 5–6 周即可完成全部训练。若首周测得的可用时段无法满足这一依赖顺序，应提前增加设备预约或统一调整计划规模。

前四周基础工作量为工程试运行、共同起始模型的 1,500 次参数更新，以及核心数据规划中的 1,200 次基准预测；校准及测试目标若按隔离要求延后运行，相应成本移到后阶段，不改变总数。按 A／B／C 假定耗时，含余量的前阶段预留分别约为 238／506／913 卡时，另加实际发生的模型输入准备、建库与查询成本。

风险评估的核心工作针对固定的 $\theta_A$。为九个继续训练模型分别建立和校准风险模型，属于额外研究；外部模型验证、对公开权重 $\theta_0$ 的额外完整评估、增加候选结构数量，以及超出计划的历史参考子集抽样稳定性检查，也需单独追加预算。80 卡时试运行仅涵盖有限的环境、稳定性和工程检查；超出该额度的调参训练或额外开发预测须单独计量，不默认包含在 19,500 次更新或 3,000 次完整预测中。

### 13.4 首周测量与超预算时的调整顺序

选择不同总长度、链长比例和 MSA 深度的输入，分别测量首次运行与已有缓存时的预测耗时、参数更新耗时、显存峰值、数据等待时间和失败率。预测计时包含全部候选结构的生成、评分与排序；训练计时包含完整参数更新涉及的模块、梯度累积和参与设备。记录每种配置的输入规模、有效批量、数值精度、更新参数范围、模板与扩散设置，再按完整实验的工作量比较成本。

**加速推理的资源核算：**首周先测量官方 OpenFold3 0.4.5 的完整预测和训练更新成本，再在不影响主线时评估第 4.6 节的可选加速实现。BioIR 或 Anthropic 的公开性能数字不能直接代替本项目的完整预测耗时，也不用于预先缩减预算。[45,46]模型推理计时包含全部候选结构的生成、置信度计算、排序与结果写出；MSA 检索、配对、模板处理及其他输入准备另记耗时和资源，并报告从原始输入到最终结果的总耗时。复用缓存时说明其来源、首次生成成本和本次命中情况。通过兼容性与结果一致性检查后，仅以实测数据更新受影响的成本项；训练参数更新仍独立测量。首次编译、权重转换或加载及失败重跑分别记录，已计入试运行的费用不重复计费。

首周同时测量特征生成、检索和成对复核的总耗时，比较相同质量要求下的中央处理器与显卡实现。超预算时优先暂停大规模内部表示提取、额外表示层、全库新建进化输入及其他条件性扩展；保留序列、配对关系、单链结构和整体组装几何及必要质量检查。若核心仍超预算，在正式登记前统一调整参数更新次数、候选结构数量或任务规模，并重估统计精度。各训练策略的样本数与训练更新预算一致；只有出现第 4.3 节规定的实质障碍时，才重新评估实施方案。

不能取消所用近似检索对应的质量验收，也不能省略正式参考范围和有效记录数。若资源只允许较小参考库，在校准前固定其范围，并限定结论。

若可用资源仍不足以完成三种策略及其重复实验，Q2 报告已完成的训练结果、可行性验证和所需追加资源，结论限定于实际完成的对照，并注明尚缺少的重复。实际费用根据 GPU、CPU 用量，以及存储和传输单价核算。

**预算边界与资源余量：**核心参考库复用已有标签坐标，不默认为全部参考重新预测。核心工作量为 3,000 次完整预测、19,500 次参数更新，其中包括九次策略训练对照。以四张设备、八周、70% 可用率计算，约有 3,763 卡时；B 情景核心约占 2,756 卡时，剩余约 1,007 卡时还要承担额外 GPU 输入准备、建库、查询及相应余量，并受排程依赖限制。扩展能否启动，要同时检查总预算和所需阶段的设备可用时段，不能把账面剩余卡时视为后阶段随时可用的资源。该算例不构成资源已经足够的保证。

## 十四、主要风险与应对措施

| 风险 | 对结果的影响 | 应对措施 |
|-|-|-|
| 生物学组装体或链对标注错误 | 将无关接触误判为预测成功或失败 | 核查组装体、链对应关系和相互作用界面的质量 |
| 历史训练资料不完整 | 无法确认目标是否在整个预训练阶段出现过 | 区分已确认的训练样本、补充参考样本和使用情况未知的样本，明确结论适用范围 |
| 参考范围不足或检索遗漏 | 将未找到近邻误认为目标在训练中缺少相似样本 | 分别检查参考规模和检索质量，记录各类有效条目与候选限制；不把当前未命中解释为全量训练集中不存在近邻 |
| 配对 MSA 信息对结果影响较大 | 难以区分训练数据覆盖程度与预测输入质量的影响 | 统一输入处理流程，在基线方法中纳入相关信息，并分组报告结果 |
| 进化谱信息不足或无可靠匹配 | 将测量不确定性误解为目标与训练集差异很大 | 进化谱扩展启用时统一匹配规则，保留质量与缺失标记并检查稳定性；资料不足不影响核心序列和几何分析资格 |
| 结构域注释不完整或表面特征提取失败 | 特征缺失与目标难度相关，造成选择偏差 | 保留目标及缺失状态，报告特征可用率，按固定规则处理缺失并限制结论范围 |
| 所选界面与训练时实际采到的界面不一致 | 数据选择干预未按计划实施 | 使用明确的界面索引，并核对实际采样日志 |
| 错误预测产生看似一致的界面特征 | 几何或表示相似可能错误地提示预测可靠 | 区分真实结构与预测结构相似性，以独立目标检验增量信息；熟悉但错误的预测形状不能直接解释为可靠，内部表示另作条件性对照 |
| 微调导致遗忘或训练不稳定 | 各种策略的预测质量均可能下降 | 统一已有样本回放比例与训练配置，以 $\theta_A$ 的结果作为参照 |
| 独立目标或失败样本不足 | 估计区间过宽，概率校准不可靠 | 首周检查样本可得性，第三周复核统计精度；必要时扩充原始结构候选库或降低结论强度 |
| 所需计算量超出可预约资源或项目期限 | 无法按期完成九次训练 | 先暂停条件性扩展，保障核心训练与独立评价；仍不足时依据实测申请资源或统一调整规模，实施方案变更仅按第 4.3 节规定的条件处理 |
| 权重、代码和历史资料不对应 | 无法解释相似性分析结果或复现实验 | 固定官方 OpenFold3 0.4.5、Preview 2 初始权重及其对应资料；保存代码与文件校验值，逐项核查接口和历史数据，另验收可选推理实现 |
| 各实验使用的模型或表示来源不一致 | 误差分析、风险评估与训练收益缺少共同参照 | 实验一、二固定 $\theta_A$；实验三从同一 $\theta_A$ 开始，选样用固定序列和几何规则；表示扩展另固定其权重与来源 |

## 十五、验收标准与后续研究

验收以实验是否按计划完成、证据是否完整可核查为依据。未观察到预期改善，也可以形成有效研究结论。

| 成果 | 验收重点 |
|-|-|
| Q1：相似性与误差的关系 | 完成单链序列、同复合物链对序列、单链结构与整体组装几何的分层对照；交付原始关系图、相关强度与区间、独立测试中的绝对及相对增量结果、可计算覆盖率和解释边界，具体产物见第 8.4 节。其他特征仅按实际启用范围验收 |
| Q1 的应用验证：预测风险评估 | 实验二报告概率校准、风险排序和结果筛选的表现，说明相似性是否具有实际使用价值 |
| Q2：训练样本选择的效果 | 实验三报告全部训练重复、实际样本选择与参数更新记录，以及独立测试集上的预测质量变化 |
| 数据、资源与复现材料 | 交付正式主清单、逐类有效记录、核心特征和索引版本、原始查询、检索质量及建库、查询、训练的实测成本；进化谱、表面与表示专项材料仅在对应扩展启用时交付 |

首周的模型平台检查与最终科学评价分别留存证据。首周验收应提供实际运行日志、参数更新记录和资源测量结果；最终报告则按两项研究问题组织，并逐项交代三个实验的结果。

Q1 的结论按误差预测、概率校准和风险筛选分别表述。例如，仅误差预测改善时，结论限定为相似性提供了额外信息，概率估计的准确性仍以实验二的结果为依据。后续研究按以下结果选择方向：

- 风险评估有实际改善，而 Q2 未发现训练收益：优先开发预测风险评估工具。
- Q2 显示训练收益：继续验证样本选择策略在更大数据量和不同任务中的效果。
- 各项实验均未发现明显收益：报告相对于基线方法可排除的效果范围，以及统计精度尚不足以判断的可能性。

可选的外部验证采用固定的公开 AFM 权重，检查少量训练数据覆盖指标能否预测其界面误差。AFM 使用的历史实验结构、蒸馏数据、MSA、模板和输出选择规则需单独核查并固定。解释跨模型差异时，需区分输入条件与模型架构的影响。[1,16]

后续可扩展至同源二聚体、更大的多聚体、抗体、蛋白—核酸及含小分子的复合物。具体范围根据核心研究结果和应用需求确定，另行规划数据、评价方法与资源。

## 十七、实施附录：建库产物、配置与新目标查询

本附录规定实施时的产物和可检查接口，不表示程序、参考库或性能测试已完成。通用清单、核心序列与几何产物为必交；参考谱、结构域、表面及内部表示文件按实际启用范围交付，未启用项目明确标记。完整命令和接口在首周核验后写入可重跑脚本。

### 17.1 参考库交付内容

| 文件或目录 | 最少包含的内容 |
|-|-|
| reference_manifest.parquet | 参考编号、来源编号、生物学组装编号、原始和内部链编号、序列校验值、训练身份、训练阶段、标签来源、数据日期、是否入库及原因；Parquet 为便于批量读取的表格格式 |
| feature_coverage.tsv | 各类特征、各类训练身份的取得数量、有效记录数、失败数、排除数及原因；分母未知时不计算全量覆盖率；TSV 为以制表符分列的文本表格 |
| sequences；profiles、domains（条件性） | 核心保存去重序列及其全部复合物归属；启用补充分析后保存同源比对、谱及结构域原始注释。JSON 为保存结构化记录的文本格式 |
| structures；interfaces（细化扩展） | 已有参考标签坐标、来源、单链与双链映射及核心几何检索文件；局部界面文件与 $\theta_A$ 参考预测仅在对应扩展启用时增加 |
| embeddings、surfaces（条件性） | 启用后保存紧凑表示、固定标准化参数与有效状态，或表面埋藏面积与组成；少量复核张量单独标记，不要求全库保存完整张量 |
| reference_config.yaml、query_config.yaml | 全部公式、参数、数据库快照、软件版本或提交、权重校验值、索引设置和时间记录；YAML 为便于人工审阅的配置文本格式 |
| raw_hits.parquet | 每个目标的候选来源、参考编号、链对应、原始分数、覆盖、状态、查询配置及参考版本；不只保存排名第一的结果 |
| similarity_features.parquet | 最终目标级相似性、最近邻编号、实际近邻数量、参考范围、质量与缺失标记，并与误差标签分开保存 |
| benchmark_report、job_ledger | 检索质量、参考规模及数值对照；首次和重复查询耗时、单目标与批量耗时、内存和磁盘；逐作业资源归属及复用记录 |

表格中的文件名为约定名称。缓存按实际依赖分别管理：MSA 与模板检索结果由输入序列、数据库快照、检索与配对规则、模板过滤及相应软件配置标识；这些条件相同时，可供不同模型权重复用。结构预测、置信度和内部表示则须另记实际使用的模型权重及计算设置。其他特征按其依赖的序列、坐标来源、软件和配置保存版本，不将模型权重设为所有缓存的统一依赖。

任一影响结果的依赖改变即生成新版本，重复运行只重算缺失、失败或已失效的记录。跨权重复用输入缓存不减少规定的结构预测次数，只避免重复准备相同输入；首次生成、后续复用和失效重算分别记录成本。

### 17.3 一个新目标的实际查询步骤

1. 核验两条输入序列及其身份，准备结构模型所需输入；先进行单链序列及同参考复合物内的链对查询。参考谱和结构域通道仅在对应方案启用时运行。
2. 用 $\theta_A$ 正常预测，按固定模型评分选出一个结构；只有内部表示方案已启用时，才同步汇总紧凑特征并记录追加耗时。
3. 以所选预测结构查询单链和整体组装几何库；局部界面、表面及表示通道仅在启用时增加。各通道独立产生候选，需要联合复核时取并集，目标真实结构不参与。
4. 在固定参考范围内复算候选分数，形成最近邻及前 5 个近邻的汇总，保留质量、缺失、训练身份和版本；不能把未返回条目填成零相似性。
5. 将特征输入已用同一参考版本训练并校准的风险模型，输出估计风险及参考条件。查询日志记录整次附加耗时，说明相对于正常结构预测增加了多少计算。

参考库一次建设后可供多个目标复用；每个新目标仍须支付自身特征计算和检索成本。库或模型更新会改变相似性分布，正式使用前重新生成受影响的开发特征并检查校准，不能直接沿用旧版本的风险关系。
