# 2026-10-19 会议摘录：abag-diversity 相关问题、任务与需求

> 来源：每周-算法研究讨论（2026-10-19 14:01–15:22）转写记录
> 范围：仅提取与本仓库相关的多样性量化评估议题；CDR mask、PLM 选型、affinity head、两阶段模型等内容不在本文范围。

## 一、定位

本仓库解决的是大项目中的一个小问题：**抗原抗体数据的多样性如何定义、如何量化、如何验证其有效性**。

它服务于两个下游决策：

- 数据要收集到什么规模（当前阶段性目标：每年约 90–100 个抗原，够不够未知）；
- 现有开源数据是否已经在多样性上高度重复（若重复，收集计划需调整）。

## 二、会议中已经明确的认识

1. **数据量与多样性是两个独立变量**，同时还要与模型参数量一并考虑。会上的判断是：需要研究「数据量 × 多样性 × 参数量」三者的匹配关系，从实验中外推出曲线，用于指导后续收集。
2. **抗原侧的表位多样性无法仅用序列刻画**。表位在三维空间上相邻，但对应残基在序列上可能相距很远（编号 10、50、100 都可能），序列相似性不足以代表表位相似性。
3. **抗体侧的多样性相对直观**。抗体有固定的 Framework、可变的 CDR，可以在 CDR 序列或结构上做聚类，阈值不同即得到不同的类别划分。但 CDR 之外也存在少量接触位点（例如极短 CDR3 时由 Framework 补偿结合），目前没有统一理论，暂按小概率事件处理。
4. **核心是接触，因此几何信息是多样性中不可忽略的一维**。会上在讨论下一步主线是结构预测的前提下，认为「接触方式」应作为影响多样性的主要因素之一——若两个抗原表位长得差不多，模型在 pair 表征阶段无法区分，多样性实际是下降的。
5. **现有的常用聚类策略仍偏主观**，没有公认标准。

## 三、问题分解

### 3.1 多样性该定义在什么空间上

可选空间彼此不等价：

| 空间 | 抗体侧 | 抗原侧 |
|---|---|---|
| 序列 | 可行（CDR 序列聚类） | 不可行（表位非连续） |
| 结构 | 可行（CDR 构象聚类） | 可行但需先定义「相似」 |
| 接触/界面 | 需要定义界面比较方式 | 需要定义界面比较方式 |

会上遗留的具体问题是：**蛋白表面（界面）究竟怎么比较**。这被单独指认为重要因素，此前已有人调研但未收敛。

### 3.2 哪种相似性是「任务相关」的

会上给出了一个可操作的判别标准：**按某种相似性聚类，若划分后模型指标显著下降，说明该维度上存在真实的数据泄漏，因而它就是对本任务有效的多样性维度。**

这为「多样性定义」提供了一个不依赖先验的筛选方法：候选维度 → 聚类 → 检查指标对划分的敏感度 → 保留敏感维度。

### 3.3 多样性与数据量的关系

需要回答：

- 在给定数据量下，多样性提升到什么程度就饱和；
- 在给定多样性下，数据量增加到多少才不再提升；
- 两者与模型参数量如何共同作用（会上同时指出参数量必须随数据量一起调整，否则必然过拟合）。

目标是外推出「多样性—准确率」曲线，反推需要收集或免疫的抗原规模。

### 3.4 多样性的度量对象是配对抗原-抗体，而非单侧

抗原表位多样性与抗体 CDR 多样性之间存在对应关系。会上指出：**在当前表位多样性可能不足的情况下，配对数据的信息量本身就不够**——即便模型侧能做到最优，也没有可学的东西。因此数据侧的多样性缺口无法靠模型弥补，这是本仓库存在的直接理由。

## 四、任务清单

**定义与度量**

- [ ] 明确抗原表位多样性的表征方式：序列 embedding 与结构/接触几何耦合后再聚类，或分别建模。
- [ ] 明确抗体侧多样性的表征：CDR 序列 / CDR 结构 / 接触残基集合，以及聚类阈值的选择依据。
- [ ] 给出「蛋白表面 / 接触界面如何比较」的具体方法（几何描述子、界面残基对、接触图谱等），并说明其在表位比较中的适用边界。
- [ ] 定义可量化的多样性指标（分布层面的熵/有效样本数，或两两距离矩阵的汇总统计），并说明其尺度含义。

**验证**

- [ ] 建立多样性维度的有效性检验流程：按候选维度聚类 → 划分训练/测试 → 观察指标下降幅度 → 判定该维度是否承载真实泄漏。
- [ ] 比较不同相似性定义下哪种划分最能解释性能差异。
- [ ] 研究数据量、多样性、参数量三者的匹配关系，拟合外推曲线，给出「多样性—准确率」的经验关系。

**数据现状**

- [ ] 对 `data/raw/public/` 下已接入的数据源做多样性摸底，输出各数据源在抗原侧、抗体侧的多样性画像。
- [ ] 检查现有开源数据之间是否存在大面积重复（表位层面，而非仅序列层面）。
- [ ] 据此复核「每年 90–100 个抗原」这一阶段性目标是否足够。

## 五、未决问题

1. 抗原表位多样性的阈值与分类体系尚无公认标准，现有聚类方法主观。
2. 表位在序列上非连续，如何在缺少结构时给出可用的多样性近似。
3. 界面比较方法未定，而它很可能是最贴近任务本质的多样性维度。
4. CDR 之外的接触位点如何纳入多样性统计（目前按小概率事件处理）。
5. 数据规模目标（90–100 抗原/年）是否够用，必须等多样性—准确率曲线出来才能回答。
