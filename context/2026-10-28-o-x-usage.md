# O/X 使用方案

<!-- 本表列出可直接采用的 O/X 组合, 用于后续对一批数据进行 S 处理（cluster/coverage）前的相似性结构定义. O 是比较对象及其分析单位, X 是可观测字段与测量协议. 用途列标记该 O/X 作用于抗体侧（AB）、抗原侧（AG）或双侧（AB / AG）. -->

| O | X | 描述 | 用途 |
| --- | --- | --- | --- |
| CDR-H3 抗体对象 | 固定编号 + 氨基酸序列 + 编辑距离 | 抗体侧按 CDR 定义对象, 序列比对给相似度 | AB |
| 抗原表面 patch | patch 残基 + 坐标 + 接触图 + 几何 | 抗原侧按表面 patch 定义对象, 几何与接触图给相似度 | AG |
| 蛋白序列 | 序列一致性 × sqrt(双向覆盖率), 带比对回溯 | MMseqs2 走序列层, identity 与覆盖相乘打分 | AB / AG |
| 单链结构 | TM 分数（双侧覆盖取 min）, 存残基对应 | Foldseek 单链比对, 独立链比对不能代表组装相似 | AB / AG |
| 局部跨链界面 | Cα 距离 ≤ 10 Å、每侧 ≥ 4 残基提取；界面分数按两侧界面长度归一 | Foldseek 界面搜索, 提取边界与链映射是协议的一部分 | AB / AG |
| 双链组装（同一空间坐标系） | min(TM_target, TM_ref), 记链映射与 complexTMscore | 保留相对链几何, 单链分数不能替代 | AB / AG |
| 定长表示向量 | 固定标准化后的余弦距离 | Faiss Flat 精确近邻基线, 不定义表示本身 | AB / AG |
| 蛋白表面 | 逐残基埋藏、界面面积、表面描述子 | FreeSASA/zsasa 表面测量, 作数值对照 | AG |
