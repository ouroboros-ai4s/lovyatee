# README

> **Lovyatee**, **/ˌloʊ.vi.jɑːˈtiː/**, 词源 Loviatar.

Lovyatee 蛋白质基础模型的数据侧仓库, data-native research.

## Description

- 盘点: 抗体-抗原 (ab / ag) 80 个公开数据来源的逐源盘点, 包括序列类型、长度分布、结构可得性.
- ETL: 围绕 Antibody CDR 与 Antigen Surface 的清洗、对齐与合并.
- 分析: 数据多样性. Surface 与 CDR 如何定义和度量, 数据规模要多大, 现有开源数据是否已高度重复.

Antibody / Antigen 是 stage 1, 之后扩展到更多 Protein 类型.
